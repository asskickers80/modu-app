# [ORDER-e1p-chip-restore-v1] 수정 진입 시 입지 칩 선택 미복원 (손실 위험)

## 판정 결과
1. 역매핑 누락 아님 — spot 3필드는 양축 역매핑에 존재, 재현 테스트에서 정상 복원.
2. 손실 없음 — 값이 저장된 유일 상가(수원 2dd2186a: 대로변/가능/좋음)는 수정 저장을
   거치고도 값 보존 중. 값이 null인 상가들(영종 등)은 기능 배포 전 등록이라 원래 없음.
   증상의 실체 = 값 없는 상가의 정상 표시 또는 실기기 구 번들 캐시로 판정.
3. 전수 대조(payload ↔ 역매핑): E1 37필드·E1p 27필드 전부 복원 확인(파생·시스템 제외),
   누락 0건.
4. 재발 방지: 소스 파싱 자동 대조 테스트 추가 — 이후 payload에 필드를 추가하고
   역매핑을 빼먹으면 테스트가 즉시 실패한다 (사진·연차·입지 유형 구조적 종결).
