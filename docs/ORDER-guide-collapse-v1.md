# [ORDER-guide-collapse-v1] 진행 가이드 완료 시 접기 — 양도인·임대인 공통

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.
■ 장치 3(양도인 diff 요약) 의무.

## 배경 (대표 확정)
가이드는 등록 완주를 유도하는 장치인데, 완주한 사용자 화면에서는 아무 일도 하지 않으면서
자리만 차지한다. 미완료 구간에서만 펼쳐 보이고, 완료 후에는 접는다.

## 동작
1. 미완료 단계 존재 시: 현행 그대로 펼침 (전 단계 목록·탭 진입 유지).
2. 등록 관련 단계 전부 완료 시: 접힌 한 줄로 축소.
   - 표시 내용은 거래 진행 상태 중심 — 예: "등록 완료 · 문의를 기다리는 중" /
     문의 있으면 "문의 N건 · 협의 진행 중" (모두 화법, 권위 어휘 금지).
   - 탭하면 펼쳐서 전체 단계 확인 가능 (기록 열람 목적, 기본은 접힘).
3. 문의받기·협의시작 단계는 정보 충실도가 아닌 거래 상태 표시이므로, 접힌 줄에서도
   상태가 드러나야 함 — 위 2번 문구가 그 역할. 완성도 카드와 중복 표현 금지.

## 판정 자율
- "등록 관련 단계 전부 완료" 판정 기준: 문의받기·협의시작을 제외한 나머지 단계 완료로
  볼지, 전 단계 완료로 볼지 — 근거와 함께 판정.
- 접힌 상태의 시각 비중(다른 카드 대비) 판정.

## 테스트
미완료/완료 분기 렌더, 접힘→펼침 토글, 문의 유무별 문구, 양축 동일 동작. 전체 스위트.

## 보고
4줄(ls-remote) + 완료 판정 기준 근거 + 양도인 diff 요약.
