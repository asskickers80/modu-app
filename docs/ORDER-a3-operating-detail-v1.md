# [ORDER-a3-operating-detail-v1] 사장님 A3 업종·지역 입력 고도화 (양도인 A3 수준)

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.

## 배경 (대표 확정)
사장님(운영중) A3의 "어떤 장사를 하고 있나요" / "가게는 어디에 있나요"가 양도인 A3
수준으로 상세해야 함. 실주소가 아니라 A3 수준(시도/시군구)까지.

## 1. 업종
- 양도인 A3의 2단계 업종 선택(categories.ts 대분류 8종 → 소분류 + 업종 직접 검색)을
  동일 적용. IndustryPicker 공용 컴포넌트 재사용, 복제 금지.
- 저장: 양도인과 동일 필드 구조(대분류·소분류) 사용. 단 축별 값이 서로 덮이지 않는지
  확인 — profile_data 단일 JSON 구조상 동명 필드 충돌 가능성 있음(기보고 사항).
  충돌하면 이번엔 수정하지 말고 현황만 보고 (별도 안건).

## 2. 지역
- 양도인 A3의 시도/시군구 2단계 선택(searchRegion 실검색) 동일 적용. 실주소(Daum)는
  이번 범위 아님.
- 저장 필드도 양도인과 동일(region·region_sub).

## 3. 공통
- 입력은 칩·검색 우선, 타이핑 최소 원칙 유지.
- 기존 사장님 A3의 다른 질문은 무변경.
- 컴포넌트 공유가 어려운 구조적 차이가 있으면 근거 보고 후 최소 확장으로 처리.

## 테스트
사장님 A3에서 업종 2단계·소분류 검색·지역 2단계 선택 후 저장·홈 반영,
양도인 A3 회귀. 전체 스위트.
