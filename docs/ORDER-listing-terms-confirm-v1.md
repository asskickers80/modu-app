# ORDER-listing-terms-confirm-v1 — 매물 등록 확인사항 (공개 직전 동의, 축별 문안)

## 모드: 자율 판정. 멈춤 (a)(b)(c)만.

## 배치
공개 직전(E1Step5·E1pStep5) 확인사항 전문 + 체크박스 1개("위 내용을 확인했으며, 사실과 다름없음을 확인합니다"). 체크 없이 공개 불가. 격식체(법적 고지문 — 모두 화법 비적용).

## 문안
공통 1·3·4·5·7·8·9(임대인은 1·4·7 렌더 조정) + 양도인 전용 2·6 + 임대인 전용 2'. 번호는 축별 1부터 재부여. 상수 파일 분리(버전 관리).

## 동의 저장
listings.terms_agreed_at(timestamptz)·terms_version(text) — SQL(a). 공개 시점 기록. 수정 재공개는 버전 동일 시 재동의 불요, 버전 변경 시 재동의. 버전 상수(v1-2026-07) 문안 파일에 명시.

## UI
전문 스크롤 영역(접힘 금지 — 고지문 노출 원칙), 체크박스↔공개 버튼 활성 연동. 미체크 시 비활성+안내.

## 테스트: 미체크 차단·체크 공개·agreed_at 기록·축별 렌더·재공개 재동의 불요. 전체.
