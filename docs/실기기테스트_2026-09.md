## T1. 하단 탭 5개 — 공용 컴포넌트로 바꾼 뒤 회귀 확인

14개 화면이 각자 갖고 있던 하단 탭을 하나로 합쳤습니다. 화면마다 탭이 잘 뜨고 눌리는지만 봅니다.

1. 앱을 열고 홈으로 갑니다. 화면 위쪽 **프로필 칩**(이름·역할이 적힌 동그란 칩)을 눌러 역할 전환 시트를 엽니다.
2. 갖고 계신 역할을 하나씩 골라 홈으로 갑니다 (양도인 → 소유주 → 사장님 …).
3. 각 홈에서 하단 탭 5개(**홈 / 탐색 / 커뮤니티 / 메시지 / 마이**)를 차례로 누릅니다.

✅ 기대 결과
- 어느 역할이든 탭 5개가 같은 자리에 있고, 현재 탭이 그 역할의 색으로 표시됩니다 (양도인 남색, 소유주 청록, 사장님 초록, 기업회원 보라).
- 메시지 탭은 역할별 문의함으로 갑니다 (양도인은 일반 문의함, 기업회원은 보라색 문의함).
- 탭을 눌러도 화면이 깜빡이거나 빈 화면이 나오지 않습니다.

## T2. 매출 입력 날짜 — 새벽에 넣어도 "오늘"로 저장

전에는 밤 12시~아침 9시 사이에 넣은 매출이 어제 날짜로 저장됐습니다. 날짜 기준을 한국 시간으로 통일했습니다.

사장님 프로필이 없으면: 프로필 칩 → **역할 추가** → 사장님 → 질문 3개(업종·지역·매출) 답합니다. **지역은 "서울 / 마포구"로 골라 주세요** (T11의 테스트 업체 주소와 맞춰야 합니다). 이미 사장님 프로필이 있으면 홈 상단에 적힌 지역을 기억해 두세요 (T11 SQL에서 씁니다).

1. 사장님 홈 맨 위 **오늘 매출** 카드에서 **[입력]** 을 누릅니다.
2. 입력 시트 위쪽 날짜 칩을 봅니다. 첫 칩이 **오늘**이고, 그 옆에 어제·2일 전… 7일 전까지 있습니다.
3. **+10만** 칩을 한 번 누르고 **저장**합니다.

✅ 기대 결과
- 카드에 방금 넣은 금액 `100,000원`이 바로 뜨고, 토스트에 "오늘 매출 10만원 저장했어요 ✓"가 나옵니다.
- (선택) 가능하시면 **밤 12시 이후~아침 9시 전**에 한 번 더 넣어 보세요. 그때도 "오늘" 칩이 실제 오늘 날짜여야 합니다. 이게 고친 버그입니다.

## T3. 주소 자동 채움 — 건축물대장 조회·확인 카드·업종 확인 칩

주소만 고르면 건축물대장에서 층·면적·준공연도를 가져와 확인 카드를 띄웁니다. 실패하면 아무 말 없이 직접 입력으로 남는 게 정상입니다.

1. 프로필 칩으로 **양도인** 홈에 갑니다. **매물 등록하기** 버튼을 누릅니다.
2. 1단계 화면에서 **[주소 검색 (도로명·지번)]** 을 누르고 검색창에 `김포한강11로` 를 입력해 목록에서 하나를 고릅니다.
   - 김포·속초 같은 저밀도 지역은 자료 커버리지가 100%라 잘 나옵니다. 홍대 같은 상업지는 8%라 안 나올 수 있습니다 (안 나와도 오류가 아닙니다).
3. 주소가 채워진 뒤 1~3초 기다립니다.

✅ 기대 결과
- 주소 아래에 **"🏢 건축물대장에서 가져왔어요"** 카드가 뜨고, 그 아래 요약 한 줄(예: `1층 · 45.2㎡ · 2009년 준공`)이 보입니다. 층·면적을 특정 못 하면 연식·용도만 나옵니다.
- **[맞아요]** 를 누르면 아래 층·면적 칸이 그 값으로 채워집니다. **[고칠게요]** 를 누르면 칸은 비어 있고 직접 입력합니다.
- 그 주소에 등록된 업소가 3곳 이하면 **"이 주소에 OO으로 등록된 곳이 있어요. 이 업종이 맞나요?"** 카드가 추가로 뜹니다. [맞아요]를 누르면 업종이 채워집니다. (업소가 많은 건물에서는 이 카드가 안 뜨는 게 정상입니다.)
- **소유주 홈 → 상가 등록하기 → 1단계**에서도 같은 카드가 뜹니다 (업종 확인 카드는 양도인만).

여기서 등록을 끝까지 하지 말고 **T4로 이어갑니다.**

## T4. 등록 초안 서버 저장 — 로그인한 사용자는 이어하기 (⚠️ 로그인 필요)

1단계에서 주소를 넣고 다음으로 넘어가면 서버에 초안이 저장됩니다. 나갔다 와도, 다른 기기에서도 이어서 할 수 있습니다.

1. T3에서 열어 둔 1단계 화면에서 상호·업종·보증금·월세·권리금·양도 방식·프랜차이즈 여부를 채우고 **[다음 — 모두가 초안 작성]** 을 누릅니다.
2. 2단계 화면이 뜨면 왼쪽 위 **뒤로**를 눌러 나가서, 하단 **홈** 탭으로 양도인 홈에 갑니다.

✅ 기대 결과
- 양도인 홈에 **"9월 9일에 하던 등록이에요 · 이어서 마저 하실 수 있어요"** 카드가 보입니다 (상호 또는 주소가 제목으로).
- 카드를 누르면 1단계로 돌아가고 아까 넣은 값이 그대로 있습니다.
- (선택) 컴퓨터 브라우저에서 같은 계정으로 로그인해 양도인 홈을 열면 **같은 카드**가 보입니다. 기기가 아니라 계정 기준으로 저장됐다는 뜻입니다.
- 초안은 탐색·내 매물 목록에는 **나오지 않습니다.** 탐색 탭에서 방금 상호가 보이면 문제입니다.

이 초안은 T5에서 **테스트 매물로 게시**해서 씁니다. 지우지 마세요.

## T10. 사장님 매출 서비스 카드 — "매출 하락" 상황 (⚠️ SQL 1회)

매출이 8주 이상 쌓여야 뜨는 카드라, 앱에서는 7일 전까지만 소급 입력이 되어 실제로 만들 수 없습니다. 테스트 매출 56일치를 SQL로 넣습니다. 전부 메모에 `TEST_SEED`가 붙어 있어 T14에서 한 번에 지웁니다.

### T10-1. SQL 실행 (컴퓨터)

```sql
-- 테스트 매출 56일치: 최근 30일 78만원 / 그 전 100만원 → 약 22~25% 하락
insert into daily_sales (device_id, user_id, sale_date, revenue, memo, source)
select
  '61b3401a-b658-49df-860a-b663a4a273e9',
  '50302ddb-8b08-43d6-8148-6ee7db3aa780',
  (current_date at time zone 'Asia/Seoul')::date - n,
  case when n < 30 then 780000 else 1000000 end,
  'TEST_SEED',
  'manual'
from generate_series(0, 55) as n
on conflict (device_id, sale_date) do nothing;

select count(*) as seeded from daily_sales where memo = 'TEST_SEED'; -- 53 (이미 기록이 있는 오늘·8/12·8/13은 건너뜀)
```

### T10-2. 휴대폰에서 확인

1. 사장님 홈을 **새로고침**합니다 (화면을 아래로 당기거나 브라우저 새로고침).
2. 오늘 매출 카드 **바로 아래**를 봅니다.

✅ 기대 결과
- 카드 한 장: 첫 줄 **"최근 한 달 매출이 이전 석 달 평균보다 25% 적어요"** (T2를 건너뛰었으면 22%), 둘째 줄 **"입력하신 매출 기준 · 홍보, 메뉴·운영 점검, 양도 상담을 알아볼 수 있어요"**, 버튼 **[알아보기]**.
- 카드 오른쪽 위에 작은 ✕(닫기)가 있습니다. **⚠️ 아직 누르지 마세요.** 누르면 30일 동안 안 보여서 T11을 못 합니다.
- 화면 어디에도 "AI"라는 글자가 없습니다.

3. **[알아보기]** 를 누릅니다.

✅ 기대 결과
- 아래에서 시트가 올라오고 제목이 카드 첫 줄과 똑같습니다.
- 칩은 **양도 상담** 하나만 보입니다. 마케팅·홍보와 메뉴·운영 컨설팅 칩은 **없어야 정상**입니다 (그 지역에 입점 업체가 아직 0곳이라 숨김). T11에서 업체를 넣으면 나타납니다.

4. **양도 상담** 칩을 누릅니다.

✅ 기대 결과
- "지금 등록하면 어떤 정보가 필요한지만 보여드릴게요" 한 줄과 **[매물 등록 미리보기]** 버튼. 등록을 재촉하는 문구가 없습니다.

5. **[매물 등록 미리보기]** 를 누릅니다.

✅ 기대 결과
- 제목이 **"매물 등록 미리보기"** 인 등록 1단계 화면이 열립니다. 칸을 눌러도 입력이 안 되고, 오른쪽 위 "예시 ✦" 버튼이 없습니다.
- 하단 버튼이 "다음"이 아니라 **[시작하기]** 입니다.
- **[시작하기]** 를 누르면 제목이 "매물 등록"으로 바뀌고 실제로 입력이 됩니다. 여기서는 바로 **뒤로** 나가 주세요 (T4 초안이 그대로 있어야 합니다).

## T11. 기업회원 문의하기·전화하기·문의함 (⚠️ SQL 1회)

기업회원 등록(E1b) 화면이 아직 저장을 안 해서 실제 업체가 0곳입니다. 테스트 업체 2곳(전화번호 있는 곳·없는 곳)을 SQL로 넣습니다. 업체의 기기 ID를 대표님 휴대폰으로 넣어서, **같은 휴대폰에서 기업회원 문의함까지** 볼 수 있게 합니다.

### T11-1. SQL 실행 (컴퓨터)

사장님 프로필 지역이 마포구가 아니면 아래 주소의 `마포구 서교동 395-1`을 그 구 이름으로 바꿔 주세요.

```sql
insert into listings (device_id, listing_type, status, shop_name, address, biz_tagline, biz_category, biz_phone, published_at)
values
  ('61b3401a-b658-49df-860a-b663a4a273e9', 'business', 'published', '테스트 홍보업체 A', '서울 마포구 서교동 395-1', '테스트용 입점 업체 (전화 있음)', 'marketing', '02-000-0000', now()),
  ('61b3401a-b658-49df-860a-b663a4a273e9', 'business', 'published', '테스트 홍보업체 B', '서울 마포구 서교동 395-2', '테스트용 입점 업체 (전화 없음)', 'marketing', null, now());

select shop_name, biz_category, biz_phone from listings where shop_name like '테스트 홍보업체%'; -- 2 rows
```

### T11-2. 시트 안 업체 목록

1. 휴대폰 사장님 홈을 **새로고침**하고 서비스 카드 **[알아보기]** 를 누릅니다.

✅ 기대 결과
- 이번엔 칩이 **마케팅·홍보 / 메뉴·운영 컨설팅 / 양도 상담** 중 **마케팅·홍보와 양도 상담** 두 개가 보입니다 (컨설팅 업체는 아직 없어서 숨김).

2. **마케팅·홍보** 칩을 누릅니다.

✅ 기대 결과
- 업체 2곳이 나옵니다. 각 행 아래 버튼: **A는 [문의하기] + [전화하기]**, **B는 [문의하기]만**. 전화번호를 등록하지 않은 업체엔 전화하기가 없어야 합니다.

### T11-3. [전화하기] — 끼어드는 화면 없이 바로 전화, 기록만

## T5. 매물 마감 흐름 3단계 — 내리기 시트·설문·다음 계획

**⚠️ 실제 매물(왓더버거 원주일산점)로 하지 마세요.** 팔렸어요를 고르면 되돌릴 수 없습니다. T4 초안을 게시해서 테스트 매물로 씁니다.

### T5-1. 테스트 매물 게시
1. 양도인 홈 "이어서" 카드 → 1단계 → 다음 → 2단계(소개글) → 3단계(사진, 건너뛰어도 됨) → 4단계에서 게시합니다.
   - 공개 직전에 **사업자등록번호 10자리**를 묻습니다. **실제 등록된 번호**(대표님 회사 번호)를 넣어야 합니다. 국세청에 없는 번호는 게시가 막힙니다. 이 번호는 비공개로 저장됩니다.
2. 양도인 홈에 방금 매물이 보이면 그 카드를 눌러 **매물 상세**로 들어갑니다.

### T5-2. 마감 시트
1. 상세 맨 아래 빨간 테두리 **[매물 내리기 (삭제하기)]** 를 누릅니다.

✅ 기대 결과: **"어떻게 됐어요?"** 시트. 칩 3개 **🎉 팔렸어요 / 😌 잠깐 쉴게요 / 💪 (계속 운영)**. 별도 "거래 완료" 버튼은 없습니다. 시트 안에 작은 "그냥 삭제" 링크가 있습니다.

2. **🎉 팔렸어요** 를 누릅니다.

✅ 기대 결과: "축하드려요 🎉" + 설문 2개 — 가격대(**처음 가격 그대로 / 10% 이내 조정 / 10~30% 조정 / 30% 이상 조정**)와 채널(**모두에서 / 부동산 / 지인·직거래**). 설문 답하면 프리미엄 1개월이 붙는다는 안내가 있고 **건너뛰기**도 됩니다.

3. 아무거나 골라 **완료**합니다.

✅ 기대 결과: **"다음은 어떻게 하실 계획이세요?"** — **다른 매물 찾을 거예요 / 다른 점포 운영 중이에요 / 당분간 쉴 거예요 / 아직 몰라요**.

4. **다른 점포 운영 중이에요** 를 고릅니다. **"임대차 만료가 언제예요?"** 에서 **⚠️ 오늘부터 2달 뒤 달**(2026년 11월)을 고르고 저장합니다. → T13·T6 재료가 됩니다.

✅ 기대 결과: "알려드릴게요. 고생 많으셨어요." 화면 → 완료. 양도인 홈에서 그 매물이 사라집니다 (삭제가 아니라 "팔림" 상태로 보관).

컴퓨터 확인 (비식별 원장에 1행, 누구인지는 없음):

```sql
select listing_type, category_main, region_gu, price_band, deal_channel, closed_on from deal_records order by created_at desc limit 1;
```

## T14. 정리 SQL — 테스트 데이터 삭제

```sql
-- 1) 테스트 업체에 달린 문의·대화
delete from inquiry_ledger where vendor_id in (select id from listings where shop_name like '테스트 홍보업체%');
delete from messages where conversation_id in (select id from conversations where listing_id in (select id from listings where shop_name like '테스트 홍보업체%'));
delete from conversations where listing_id in (select id from listings where shop_name like '테스트 홍보업체%');
-- 2) 테스트 업체
delete from listings where shop_name like '테스트 홍보업체%';
-- 3) 테스트 매출·카드 노출 이력
delete from daily_sales where memo = 'TEST_SEED';
delete from sales_card_impressions where device_id = '61b3401a-b658-49df-860a-b663a4a273e9';

select
  (select count(*) from listings where shop_name like '테스트 홍보업체%') as vendors,   -- 0
  (select count(*) from daily_sales where memo = 'TEST_SEED') as seeds,                -- 0
  (select count(*) from daily_sales) as real_sales;                                     -- 2 (+T2에서 넣은 오늘 1)
```
