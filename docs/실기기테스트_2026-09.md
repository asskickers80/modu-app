# 1부. 기본 기능 (휴대폰만)

## T1. 하단 탭 5개 — 공용 컴포넌트 회귀

1. 홈 위쪽 **프로필 칩**을 눌러 역할 전환 시트를 엽니다.
2. 갖고 있는 역할을 하나씩 골라 홈으로 갑니다 (양도인 → 소유주 → 사장님 …).
3. 각 홈에서 하단 탭 **홈 / 탐색 / 커뮤니티 / 메시지 / 마이**를 차례로 누릅니다.

✅ 어느 역할이든 탭 5개가 같은 자리에 있고 현재 탭이 역할 색(양도인 남색·소유주 청록·사장님 초록·기업회원 보라). 메시지 탭은 역할별 문의함. 빈 화면·깜빡임 없음.

## T2. 매출 입력 날짜 — 새벽에도 "오늘"

사장님 프로필이 없으면 프로필 칩 → **역할 추가** → 사장님 → 질문 3개. **지역은 서울 / 마포구, 업종은 카페·베이커리 계열**로 골라 주세요 (뒤의 SQL 데이터와 맞춰야 합니다).

1. 사장님 홈 **오늘 매출** 카드 → **[입력]**.
2. 날짜 칩 첫 칸이 **오늘**, 옆에 어제 … 7일 전.
3. **+10만** → **저장**.

✅ 카드에 `100,000원`, 토스트 "오늘 매출 10만원 저장했어요 ✓". (선택) 밤 12시~아침 9시 사이에도 "오늘" 칩이 실제 오늘이어야 합니다.

## T3. 주소 자동 채움 — 건축물대장 카드·업종 확인 칩

1. **양도인** 홈 → **매물 등록하기**.
2. **[주소 검색 (도로명·지번)]** → `김포한강11로` 검색 → 하나 선택. (김포·속초는 자료 100%, 홍대 같은 상업지는 8%라 안 나올 수 있음 — 오류 아님.)
3. 1~3초 기다립니다.

✅ "🏢 건축물대장에서 가져왔어요" 카드 + 요약(예: `1층 · 45.2㎡ · 2009년 준공`). **[맞아요]** → 층·면적 채워짐, **[고칠게요]** → 직접 입력. 같은 지번 업소가 3곳 이하면 "이 주소에 OO으로 등록된 곳이 있어요. 이 업종이 맞나요?" 카드 추가. 소유주 상가 등록 1단계도 같은 카드(업종 카드는 양도인만).

등록을 끝내지 말고 T4로 이어갑니다.

## T4. 등록 초안 서버 저장 + 이어하기 → 테스트 매물 게시 (⚠️ 로그인)

1. 1단계에서 상호·업종(**카페·베이커리 계열**)·보증금·월세·**권리금 3,500**·양도 방식·프랜차이즈 여부를 채우고 **[다음 — 모두가 초안 작성]**.
2. 2단계가 뜨면 **뒤로** → 하단 **홈**.

✅ 양도인 홈에 **"9월 10일에 하던 등록이에요 · 이어서 마저 하실 수 있어요"** 카드. 누르면 값이 그대로. 컴퓨터에서 같은 계정으로 봐도 같은 카드(계정 기준). 탐색·내 매물 목록에는 안 나옴.

3. 카드를 눌러 **끝까지 게시**합니다: 2단계(소개글) → 3단계(**사진은 올리지 마세요** — U10 재료) → 4단계 게시. 공개 직전 **실제 사업자등록번호 10자리**가 필요합니다(국세청에 없는 번호는 막힘, 비공개 저장).

✅ 양도인 홈에 방금 매물이 보입니다. 이 매물을 이 문서에서 **"테스트 매물"**이라고 부릅니다. 실제 매물(왓더버거 원주일산점)은 건드리지 않습니다.

## U10. 완성도 '다음 1개' 카드

1. 양도인 홈에서 내 매물 카드 **바로 위**를 봅니다.

✅ 남색 카드 **"다음 1개"** — **"사진을 올리면 완성도 N→M점 · '충실한 매물' 배지가 붙어요"**(M이 80 이상일 때만 배지 문구). 두 점수가 다릅니다. "사진 슬롯을 늘릴 수 있어요" 문구는 **없음**(무료 5장을 다 안 썼으니).

2. 카드를 누릅니다.

✅ 사진 단계(3단계) 수정 화면으로 이동. 여기서 사진을 **1장** 올리고 4단계까지 가서 수정 완료.

3. 양도인 홈으로 돌아옵니다.

✅ 카드 문안이 **"사진 2장을 더 올리면 권장 3장이 채워져요 · 완성도 M점"**(점수 하나)으로 바뀝니다. 사진 3장을 채우고 나머지도 다 채우면 카드가 **사라집니다**.

4. 테스트 매물 상세(내 매물 카드 → 상세)에서 위쪽을 봅니다.

✅ 같은 '다음 1개' 카드가 소유자 뷰 상단에도 있습니다.

## T10. 매출 서비스 카드 — 매출 하락 (⚠️ SQL)

앱에서는 7일 전까지만 소급 입력이 되어 8주치를 만들 수 없습니다. 테스트 매출 56일치를 SQL로 넣습니다(메모 `TEST_SEED`, T14에서 삭제).

### T10-1. SQL (컴퓨터)
```sql
insert into daily_sales (device_id, user_id, sale_date, revenue, memo, source)
select
  '61b3401a-b658-49df-860a-b663a4a273e9',
  '50302ddb-8b08-43d6-8148-6ee7db3aa780',
  (current_date at time zone 'Asia/Seoul')::date - n,
  case when n < 30 then 780000 else 1000000 end,
  'TEST_SEED', 'manual'
from generate_series(0, 55) as n
on conflict (device_id, sale_date) do nothing;
select count(*) as seeded from daily_sales where memo = 'TEST_SEED'; -- 53
```

### T10-2. 휴대폰

✅ 카드 1장: **"최근 한 달 매출이 이전 석 달 평균보다 25% 적어요"**(T2를 건너뛰었으면 22%) / "입력하신 매출 기준 · 홍보, 메뉴·운영 점검, 양도 상담을 알아볼 수 있어요" / **[알아보기]**. "AI" 글자 없음. **⚠️ 오른쪽 위 ✕는 아직 누르지 마세요.**

2. **[알아보기]**.

✅ 시트 제목 = 카드 첫 줄. 칩은 **양도 상담** 하나만(입점 업체 0곳이라 마케팅·컨설팅 칩 숨김). 칩 목록 맨 아래 회색 글씨 **"정부 지원제도도 확인해 보세요"**(U11에서 사용).

4. **[매물 등록 미리보기]**.

✅ 제목 **"매물 등록 미리보기"**, 입력 불가, "예시 ✦" 없음, 하단 **[시작하기]**. [시작하기]를 누르면 제목이 "매물 등록"으로 바뀌고 입력 가능. 여기서는 **뒤로** 나갑니다.

### T11-2. 시트 안 업체 목록
1. 사장님 홈 새로고침 → 서비스 카드 **[알아보기]**.

✅ 칩이 **마케팅·홍보 / 양도 상담** 두 개(컨설팅은 여전히 0곳).

2. **마케팅·홍보**.

## ⚠️ 2부 공통 — 하루 상한과 "상한 초기화" SQL

찜 알림은 **같은 매물에 하루 1건, 사용자당 하루 3건**만 갑니다(설계값). 그런데 이 테스트는 하루에 같은 매물로 알림을 3~4번 만들기 때문에, 두 번째부터는 상한에 걸려 **안 오는 것이 정상**입니다. 각 알림을 따로 보려면 단계 사이에 아래 SQL을 실행해 오늘 보낸 찜 알림을 "어제 것"으로 돌립니다(테스트 기간에만 쓰는 방법입니다).

```sql
-- 상한 초기화: 오늘 만든 찜 알림을 하루 앞으로 당긴다 (내용은 그대로, 상한 계산에서만 제외)
update notifications set created_at = created_at - interval '1 day'
where type like 'watch_%' and created_at >= (current_date at time zone 'Asia/Seoul')::timestamptz;
```

U1 직후 컴퓨터에 🔥 **"이 매물은 이번 주 관심이 많아요"**(같은 매물 찜 7일 5건 → 1회)가 와 있을 수 있습니다. 그러면 오늘 그 매물의 1건은 이미 쓴 것이라, **U3·U4·T5 각각 직전에 초기화 SQL을 한 번씩** 실행하세요.
