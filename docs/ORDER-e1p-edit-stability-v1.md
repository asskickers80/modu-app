# ORDER-e1p-edit-stability-v1 — 수정 모드 불안정 (경로별 조사 후 수정)

## 증상 (실기기, c4dbeef)
1. 홈 상가 카드→수정 진입: 단계 칩 보임(수정 인식) → Step2 극장 재생.
2. 수정 진입 후 브라우저 뒤로가기 홈 복귀 → 빈 CTA 렌더. 새로고침 복원 여부 조사 포함.

## 조사(수정 전 원인 보고)
1. 진입 경로 대조(홈 vs E2L) — 극장 생략 분기 조건이 홈 경로에서 무엇이 달라 무력화되는지. 유력: edit 파라미터가 Step 이동 시 소실 / 초안 로드 전 Step2 마운트.
2. 뒤로가기 홈 붕괴 — 컨텍스트 오염 vs 목록 fetch 스킵 vs 히스토리·SPA 경합.
3. E1(양도인) 동일 증상 대조.

## 수정: 판정 소스 단일화(경로 무관) + 홈 복귀 목록 재조회 보장. 경로 2종×뒤로가기 테스트. 기존 테스트가 홈 경로를 놓쳤다면 경위 정직 보고.
