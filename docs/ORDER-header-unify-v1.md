# [ORDER-header-unify-v1] 헤더 통일 — 알림 전 축 적용 + 정체불명 아이콘 정리

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.
■ 장치 3(양도인 diff 요약) 의무.

## 증상 (실기기)
사장님(운영중) 홈 헤더에만 알림 벨(빨간 점)과 정체불명 아이콘 1개가 추가로 존재.
다른 축 헤더에는 없음 — 축별 헤더가 개별 구현되며 생긴 불일치로 추정.

## 1. 현황 조사 (보고 필수)
- 5축 홈 헤더의 요소 구성 전수 대조표 (프로필 칩 / ModuMark / 알림 / 기타 아이콘 / ⋯).
- 사장님 헤더의 추가 아이콘 2종 각각의 정체·동작 보고 (알림 벨, 그 옆 아이콘).
  옆 아이콘이 실동작하는 기능인지, 미구현 껍데기인지 판정.
- 헤더가 공용 컴포넌트인지 축별 복제인지 확인.

## 2. 통일
- 헤더를 공용 컴포넌트로 통일 (복제면 추출). 축별 차이는 색상·라벨 등 데이터 수준만.
- 알림: 전 축 공통 적용. 알림 데이터 소스·미읽음 판정은 기존 unread 단일 소스 재사용
  (UnreadDot 규격). 알림 화면이 미구현이면 그 사실을 정직 표시하거나 (예정) 처리 —
  껍데기 벨만 다는 것 금지, 판정 근거 보고.
- 정체불명 아이콘: 실동작이면 전 축 적용 여부 판정 후 통일, 미구현 껍데기면 제거
  또는 (예정) 규격 처리.

## 3. 알림 내용 범위 (판정 후 보고)
현재 알림에 들어갈 실이벤트가 무엇인지 목록화 — 새 문의, 답장, 관심(향후),
폐업 확인 카드 등. 실이벤트가 없으면 벨을 다는 것 자체가 이르므로 그 판단도 보고.

## 테스트
5축 헤더 동일 구성, 알림 표시·해제, 미구현 요소 부재. 전체 스위트.

## 보고

양도인 diff 요약.
