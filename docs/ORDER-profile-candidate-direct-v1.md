# [ORDER-profile-candidate-direct-v1] 프로필 후보 칩 → A2 건너뛰고 해당 축 A3 직행

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.

## 증상·원칙 (대표 확정)
프로필 전환 시트의 "다른 카테고리로 추가" 칩을 탭하면 A2(역할 선택 첫 화면)로 이동해
같은 선택을 반복하게 됨. 칩 탭 = 이미 그 역할을 고른 행위이므로, A2를 건너뛰고
해당 축 A3(질문)로 직행한다.

## 구현
1. 칩 탭 → 해당 카테고리의 A3로 직행. 역할은 칩에서 확정 전달 (기존 preset 죽은
   파라미터 폐기 또는 실동작화 — 어느 쪽이든 A2 경유 없이).
2. A3 완료 → 기존 completeLoggedInRoleAdd 경로로 즉시 추가 + 해당 축 홈 진입
   (직전 오더 구현 재사용, A4 미노출 유지).
3. 방문자 칩은 현행 유지 (A3 없으므로 시트에서 즉시 추가).
4. A2에서 시작하는 일반 온보딩 경로는 무변경.
5. 뒤로가기 처리: A3에서 뒤로가면 A2가 아니라 이전 화면(홈·시트)으로 복귀 —
   존재하지 않는 단계로 돌아가지 않도록.

## 테스트
칩 탭 → A2 미노출·해당 축 A3 진입 → 완료 → 즉시 추가·활성 전환·홈 진입 /
뒤로가기 복귀 지점 / 방문자 칩 현행 / A2 일반 경로 회귀. 전체 스위트.
