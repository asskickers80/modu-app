# [ORDER-landlord-completeness-v1] 임대인 완성도 배점 구현 — calcScoreLandlord

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.

## 배점 (대표 확정, 100점)
1. 기본 정보 완비 20: 주소+상세 5 / 면적·층 5 / 거래유형별 가격 조건 완비 10
   (임대=보증금·월세, 매각=매매가, 둘다=양쪽 모두).
2. 임차 현황·수익률 15: occupancy 응답 5 / 수익률 산출 가능 10
   (매각·둘다: cap_rate 산출 / 임대 단독: 현 임대료 입력 시 10).
3. 사진 25: 외관 1장 10 / 3장 이상 +5 / 도면 1장 이상 +10.
4. 소개글 20: 초안 확정(confirmedAt) 10 / 소유주 수정 흔적(edited_texts) +5 /
   전 블록 공개(item_visibility) +5.
5. 위치 공개 10: 지도·거리뷰 공개 ON.
6. 부가 정보 10: 권장 업종 5 / 입주 가능 시점·권리관계 5.

## 구현
1. lib/completeness에 calcScoreLandlord 구현 — 기존 준비중 스텁 대체.
   양도인 calcScore와 공유 가능한 판정 유틸은 추출·재사용 (복제 금지).
2. 홈 ⑦ 완성도 카드: 준비중 → 실점수 전환. 양도인 동형 표시 —
   % + 다음 액션 힌트 ("도면을 추가하면 완성도가 올라가요" 류, 모두 화법,
   최저 점수 항목 우선 제시).
3. E1p 저장·수정 시 재계산. 복수 상가는 상가별 점수, 홈 카드는 대표(최저 또는
   활성 상가) 표시 판정 Code 자율 — 근거 보고.
4. 원칙 명시: 완성도 = 정보 충실도. 질 평가·랭킹 판매 아님 (주석·문서에 기록).

## 테스트
배점 경계 케이스 (임대/매각/둘다 × 항목별 유무), 0점·100점 양극,
힌트 문구 최저 항목 매칭. 전체 스위트.
