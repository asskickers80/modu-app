# 알림 센터 설계 메모 (ORDER-notification-bell-v1 §4 — 문서만, 구현 아님)

## 원칙
- 벨 = **"모두(플랫폼)가 사용자에게 보내는 알림" 전용**.
- **사용자 간 활동(새 문의·답장·안읽은 메시지)은 벨에 포함하지 않는다** —
  메시지 탭 점(MessageTabDot)·홈 문의 지표(MetricsPanel)가 담당. 중복 표시 금지.
- 상시 점 금지: 미확인 "모두 발송" 알림이 있을 때만 UnreadDot(단일 소스) 표시.

## 향후 "모두 발송" 알림 이벤트 후보
| 이벤트 | 소스 | 비고 |
|---|---|---|
| 폐업 확인 요청 | 국세청 상태조회 배치(api/check-business-closure) 감지 | 현재는 홈 확인 카드(ClosurePrompt)로 노출 — 알림 센터 도입 시 벨과 병행 |
| 일정 알림 | 임대료·부가세 등 역산 파생 | **일정관리 로드맵과 도메인 규칙표 공유** |
| 매칭 제안 | AI 정제 양면 매칭 고도화 | **매칭 로드맵과 도메인 규칙표 공유** |
| 시세·상권 변동 | 인근 실거래 신고 감지 | 등록 매물 주소 반경 기준 |
| 공지·정책 변경 | 운영 발송 | 이용약관·기능 공지 |

## 구현 시 교체 지점 (구조 정리 완료)
- 벨·점·탭 동작은 `src/components/HomeHeaderBar.jsx` 한 곳 — 5축 동시 반영.
- 탭 동작: 현재 (예정) 토스트 → 알림 센터 라우트로 **이 지점만** 교체.
- 미확인 판정: 알림 테이블(발송·읽음 시각) 신설 후 `hasNotification` prop에 연결,
  점은 UnreadDot 규격 그대로.
