# [ORDER-listing-title-v1] 매물 제목 — 소유주 직접 편집 (양도인·임대인 공통)

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만. 장치 3 의무.

## 원칙 (대표 확정)
제목은 소유주의 것. 자동 생성은 초안이며 최종 결정권은 소유주에게 있다.
시스템 자리 채움 문구("이름 미정 상가" 등) 노출 금지.

## 구현
1. title 컬럼 신설 (스키마 SQL 제시 후 멈춤 a).
2. 자동 초안: 임대인 "팔달구 인계동 1층 54㎡ 상가" / 양도인은 상호 공개 토글 존중
   (비공개면 상호·브랜드 미포함 "인계동 1층 카페 매물").
3. 공개 직전 단계에 초안 채워진 입력창(TitleEditField 공용), 수정 왕복 보존.
4. 표시 전 지점(E2·E2L·홈·탐색·인박스 카드 등)이 displayTitle 단일 소스 참조,
   "이름 미정" 폴백 제거.
5. 등록 확인사항 4조 고지 문구 (강제 검열 없음).

## 정합 점검 결과
기존 displayShopName은 상호 비공개+프랜차이즈에서 "동 + 브랜드명"을 노출 —
토글 무력화 구멍 실재. displayTitle은 비공개 시 상호·브랜드 절대 미포함.
임대인 상가의 shop_name(현 임차인 상호)도 제목에 쓰지 않는다(임차인 특정 방지).
