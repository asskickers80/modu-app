# [ORDER-industry-banner-per-listing-v1] 업종 재확인 배너 — 매물 단위로 전환

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.

## 증상 (실기기)
양도인 홈 "업종을 새 분류로 확인해주세요" 배너가 프로필 단위 단일 선택으로 보임.
매물 2건(서로 다른 업종 가능)인데 칩 하나를 고르면 어느 매물에 적용되는지 불명확.

## 원칙 (대표 확정, [공통])
업종 재확인은 매물 단위. 미확인 매물을 지목해 그 매물의 업종만 채운다.
복수면 각각 따로. 프로필 단위 일괄 지정 금지.

## 수정
1. 배너 대상 판정: 새 분류 미확인 매물 목록 조회, 0건이면 미표시.
2. 표시: 대상 매물 명시(상호/주소 요약 + 썸네일). 복수 처리 방식은 Code 판정.
3. 저장: 해당 매물 행에만 반영, 다른 매물·프로필 불변 테스트.
4. 닫기: 세션 한정("다음에") 확인·유지, 완성도·가이드 집계는 계속 미확인.
5. 헤더 정합: 복수 매물 업종 표기 방식 판정.

## 임대인 동일 검사
같은 형태 배너·안내 전수 확인, 있으면 동일 원칙 / 없으면 없음 보고.

## 보고

양도인 영향 diff 요약(장치 3).
