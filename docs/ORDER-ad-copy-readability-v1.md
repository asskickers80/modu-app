# [ORDER-ad-copy-readability-v1] 매물 광고 본문 가독성 — 전용 타이포

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.

## 대상
E2·E2L 상세의 AI/소유주 작성 본문 단락 전부 (시설·매출·상권·설명문·프랜차이즈·
시세 해석 등 블록 본문) + E1/E1p 검수 화면의 같은 본문 (검수=광고 동일 원칙).
리스트 항목(시설 목록 등)·숫자 강조는 현행 유지 — 본문 단락만.

## 스타일
- 크기: 본문 단락 확대 (Code가 390px 실측 판정, 리스트와 위계 역전 금지 —
  본문이 섹션 제목보다 커지면 안 됨).
- 행간: leading 1.6~1.7 수준 판정 포함.
- 단락 간격: 문장 덩어리 분리감 확보.
- 토큰 방식: 광고 본문 전용 클래스(ad-body)를 타이포 토큰 위에 정의 —
  개별 화면 하드코딩 금지, 이후 조정 한 곳 원칙 유지.

## 테스트
전체 스위트 그린(로직 불변). 대상 블록 전수에 클래스 적용 확인.
