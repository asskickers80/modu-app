## 이미 등록된 시점 조건 (다른 문서)

창업준비 '우선순위 1개' 온보딩 — 창업준비 프로필 300개 또는 매물 평균 찜 5건이 되면 실행. 채팅 쪽에서 매월 1일 확인.
창업준비 프리미엄 패키지(B-9) — 창업준비 프로필 300개 또는 매물 평균 찜 5건 → '우선순위 1개' 온보딩과 같은 시점에 채팅 쪽이 함께 안내(매월 1일 확인).

## 방향 원칙 (백로그 항목 아님, 작업 중 항상 적용)

- 부동산·컨설팅 업체는 모두의 경쟁자도 제휴 상대도 아니다. 자기 매물과 고객을 위해 스스로 들어와 매물을 올리고 문의를 받는 사용자다. 기업회원 관련 코드·문안·주석에 "제휴", "연동 계약", "매물 공급처" 표현을 쓰지 않는다.
- 저가·AI 대체 가능 서비스도 남에게 넘기지 않고 모두가 흡수한다(B-4). 기업회원 축을 "현장·고가 서비스 전용"으로 좁히는 설계를 하지 않는다.
- 정책·제도 정보는 자체 챗봇을 만들지 않고 정부 서비스(소상공인365·소상공인24)로 연결한다. 모두의 AI는 '내 가게 시세·문의'에만 쓴다(대표 결정 2026-09-10).
- 화면의 모든 수치에는 출처 라벨 4종 중 하나가 붙는다: "공식 자료(기관·기준일)" / "모두가 본 것(기록일)" / "양도인이 적은 값" / "내가 넣은 값". 라벨 없는 숫자는 만들지 않는다. "확인됨·검증·인증·믿을 수 있는·안전한" 단어는 쓰지 않는다(카드매출 연동은 "연동된 카드매출 기준 · 현금 매출 미포함"). 판정 문구(좋다·나쁘다·위험하다·부풀려졌다)는 쓰지 않는다 — 사실 두 개를 나란히 놓는 것까지가 모두의 일이다(대표 결정 2026-09-11).
- 등록값이 공식 자료와 다를 때는 양도인·소유주에게도 같은 화면을 보여준다. 한쪽에만 보여주고 한쪽에 숨기는 설계를 하지 않는다.
- 타 플랫폼(네이버 플레이스·카카오맵 웹·배달앱) 페이지 크롤링·자동 수집은 하지 않는다. 공식 API와 공공데이터만 쓴다(네이버 vs 다윈중개 특허법원 2025.12.24 판결, 대표 결정 2026-09-11).
- 시세 문의는 법인 설립 전까지 기업회원(부동산·상담) 경유. 입구는 '모두에 시세 물어보기' 하나, 원장은 모두 것, 법인은 같은 파이프라인에 기업회원 하나로 들어온다(대표 결정 2026-09-11).
- 사용자 작성 후기는 두 종류만: ① 매물 방문·답사 후기(매물 단위, 별점·평가 없음, 소유주·양도인 삭제권) ② 기업회원 후기(로그인 회원 누구나, 별점 없음, 기업회원은 삭제 대신 이의신청→30일 임시 블라인드). 자리(장소) 단위 후기·이력(B-5)은 계속 만들지 않는다. 후기 작성·열람은 전부 로그인 회원만(대표 결정 2026-09-09, 2026-09-12 갱신).
- 매물 공개는 public|quiet 두 단계. quiet는 상호·사진·정확 위치를 서버에서 마스킹하고 찜·문의는 받는다. 자동 공개 없음, 정렬·노출에서 visibility를 키로 쓰지 않는다, 좋은 점·대신(페널티)은 등록 화면에 항상 나란히(대표 결정 2026-09-12).
- 기업회원 프로필의 '함께 일한 사장님 한마디'는 초대 링크·업체 승인제(최대 3개, 무료·유료 공통)이고 후기와 같은 화면에서 서로 다른 고정 문안으로 구분한다. 매물·양도인에는 붙이지 않는다(대표 결정 2026-09-12).
- 모델은 우리 데이터로 학습하지 않는다. 성장하는 것은 질문 로그·등록 항목·문의 원장이다. 답변 정확도를 올리려면 모델이 아니라 화이트리스트 데이터를 넓힌다(대표 확인 2026-09-13).
- 탐색 결과가 0건·소수건일 때는 대화창이 아니라 '조건 풀기' 칩(실제 건수 붙은 완화 후보 최대 3개, 한 번에 한 칸, 최대 두 칸 조합)과 '이 조건 새 매물 알림'을 둔다. AI 호출 없음. 참고: 네이버지도 플레이스 에이전트 2026.9.17(결과 0건 자리에 진입점). 나중에 질문 창(9/7 구조)이 붙으면 되묻기 칩이 이 완화 함수를 재사용한다(대표 결정 2026-09-21).
- 판매자 우선(대표 결정 2026-09-15): 모두는 파는 사람(양도인·소유주)이 가장 중요한 플랫폼이다. 판매자에게 불리한 정보(가격 인하 이력·변동 횟수·등록 경과일 등 시간 축 정보)를 다른 사용자에게 노출하는 기능은 유료·무료를 불문하고 만들지 않는다. 판매자에게 유리하거나(최근 확인일, 정보 추가) 판매자가 스스로 켜는 신호(찜한 분들께 알리기, 거래가 공개 동의)만 허용한다. 타 사용자 화면에 등록일·가격 변동을 찍는 컴포넌트는 lint 실패.
