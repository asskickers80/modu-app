# [ORDER-brokers-entry-only-v1] 내 주변 부동산 — 홈 상시 노출 폐지, 등록 진입 시점 한정

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만. 장치 3 의무. (nearby-brokers-v1 정책 개정)

## 정책 (대표 확정)
부동산 노출은 "새 매물/상가 등록" 진입 시점에만. 홈 상시 노출 폐지 — 상시 노출은
무료 광고판이고, 희소해야 자리에 값이 생긴다. 등록 진입 = 리드 품질 최고 순간.
사용자에게는 "등록 전에 참고할 수 있는 정보"로만 존재.

## 구현
1. 홈 카드 제거 (양축) — 컴포넌트는 유지·재사용, 홈 진입 시 관련 조회 0회.
2. E1·E1p 1단계 하단 노출 — 참고 정보 톤, 권유 문구 금지. 표시 격차·슬롯 로직 유지.
3. 위치 기준 = 사용자 현재 위치(geolocation). 권한 요청은 이 시점에만 맥락과 함께,
   거부·실패 시 조용히 생략(재요청 금지). A3 지역 폴백 미사용(시·도 단위 — 정밀도 부족).
   캐시: 좌표 기준 일 1회.
