1. 수정 모드 단계 자유 이동(강제 완주 폐지) — E1 구조 준용, 다르면 통일(현황 보고).
2. Step2 수정 진입 시 기존 글 편집 기본. 로딩 극장 재실행 금지 — 실기기 재생성 원인((a)회귀 (b)연출만 (c)초안 미저장) 특정+수정. 재생성·2안 비교는 E1 컴포넌트 재사용.
3. Step5 공개 중 수정 시 재검수·재공개 요구 금지 — 저장 시 공개 유지. 동의 스킵 확인.
4. E1 회귀 재검증.
