# [ORDER-typography-scale-v1] 전 앱 타이포그래피 확대 — 토큰화 + 계층별 차등

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.

## 배경 (대표 확정)
전 화면 가독성 부족 — 특히 섹션 제목이 눈에 안 잡힘. 주 사용자(40~60대 자영업자·
소유주) 기준 기본 폰트 자체를 확대. 스크롤 길어지는 것 수용. 미결 #7(고령 UI)의
기본 해법 — 별도 큰 글씨 모드 대신 기본을 키운다.

## 1. 타이포그래피 토큰 신설 (단일 소스)
글자 크기·굵기·행간을 토큰으로 정의하고 전 화면이 참조하는 구조(9색 토큰과 동일 위상).
계층: 페이지 제목 / 섹션 제목 / 본문·리스트 / 보조(라벨·날짜·힌트) / 버튼.
구현 방식(tailwind config 스케일 재정의 vs CSS 변수 vs 공용 클래스)은 Code 판정 —
기존 코드 침습 최소·이후 조정 한 곳 원칙, 근거 보고.

## 2. 스케일 (계층별 차등)
- 본문·리스트 +15~20% / 섹션 제목 +10~15%+굵기 보강 / 보조 +10%(위계 보존) /
  버튼 +15%+터치 44px / 페이지 제목 +10%(과확대 금지).
- 390px 뷰포트 줄바꿈 붕괴(제목 2줄화·버튼 텍스트 넘침) 전수 점검 포함.

## 3. 적용 범위
전 앱 공통. 축별 개별 크기 지정은 토큰 참조로 교체(하드코딩 잔존 grep — 예외는
목록·근거 보고).

## 4. 보호장치
시각 변경 전용 — 로직·동작·문구 변경 일체 금지. 전체 테스트 그린이 증거.
주요 화면 목록(홈 2축·E1p 1단계·E2L·D4·탐색)을 보고에 명시해 대표 확인 동선 제공.
