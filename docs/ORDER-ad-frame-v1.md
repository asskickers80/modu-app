# [ORDER-ad-frame-v1] 광고 틀 재편 통합 — 카테고리 구조 + 가독성 + 입지 블록

■ 모드: 자율 판정. 멈춤 (a)스키마 SQL (b)실DB 정정 (c)판정 불가만.
■ 적용: E2·E2L + 검수 화면(검수=광고 동일 원칙). 장치 3(양도인 diff 요약) 의무.
■ 주의: ORDER-ad-copy-readability-v1을 흡수한 유일본 (2번 항목).

## 1. 카테고리 그룹 구조
- 양도인(E2): 기본 정보 → 시설 → 영업(매출·프랜차이즈) → 입지 → 상권 → 경쟁력 → 위치(지도)
- 임대인(E2L): 기본 정보 → 시설·건물 → 거래 조건 → 입지 → 상권 → 경쟁력 → 위치(지도)
- 상단 앵커 탭(B안): 섹션 가로 탭 — 탭 시 점프, 스크롤 시 현재 섹션 하이라이트.
  EditStepTabs 문법 준용, 컴포넌트 공용 추출(복제 금지).
- 비공개·해당 없음 블록은 섹션째 생략 — 빈 섹션 헤더 금지.

## 2. 본문 가독성 (ad-copy-readability-v1 흡수)
ad-body 전용 클래스: 크기 확대(390px 실측·위계 역전 금지) + 행간 1.6~1.7 + 단락 간격.
대상은 AI/소유주 작성 본문 단락 전부. 리스트·숫자 강조는 현행 유지. 조정 한 곳 원칙.

## 3. 입지 블록 신설 (상권과 층위 분리)
정의: 상권 = 동네 단위 / 입지 = 이 건물·이 점포의 자리.
- a. 소유주 입력 칩: 도로 접면(대로변/이면도로/코너) · 주차(가능/불가/인근 공영) ·
  (선택) 전면 노출(좋음/보통). 저장 컬럼 SQL 제시 후 멈춤(a), 수정 왕복 보존 테스트 필수.
- b. 좁은 반경: 소진공 API 50~100m 재조회 — "바로 이 자리 주변" 업종 구성.
  캐시·호출 횟수 판정 자율(비용 원칙), 근거 보고.
- c. 생성: 층수·접면·주차 + 좁은 반경 실값 + 그라운딩 정성. 날조 금지·분량 규칙 동일.
- d. 배치: 입지 섹션 = 지도 섹션 바로 앞.

## 4. 기존 매물 처리
입지 칩 미입력 매물: 재료(좁은 반경·그라운딩)만으로 생성 가능하면 생성, 부족하면 블록 생략.
소급 재생성 배치 없음(자연 갱신).
