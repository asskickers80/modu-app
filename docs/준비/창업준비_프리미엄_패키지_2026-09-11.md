창업준비 프리미엄 패키지 — 준비 문서 (2026-09-11, 시행 보류)
대표 결정(2026-09-11): 창업준비자도 구독하게 하는 방향은 확정. 단 지금은 만들지 않는다. 창업준비자·알아보는 사람 입장에서 구독까지 갈 만큼 혜택이 아직 부족하다. 혜택을 여러 방면으로 더 검토한 뒤 패키지 하나로 묶어서 내놓는다. 이 문서는 그때 꺼내 쓰는 재료이고, 아래 "검토 시점"이 되면 Claude Code와 채팅 양쪽이 대표에게 상기한다.
1. 지켜야 할 기준 (확정 — 지금부터 적용)
기준 1. 이미 발품·돈을 쓰는 일을 대신하는 것만 판다. 무료보다 조금 더 보여주는 건 혜택이 아니다.
기준 2. 남의 협조 없이 돌아가야 하고, 모두가 남의 주장을 보증하는 모양이 되면 안 된다. 양도인·소유주가 협조해야 생기는 것(매출 증명, 수익 증명)은 협조가 없으면 무용하고, 거짓이면 모두가 책임을 진다 — 프리미엄의 근거로 쓰지 않는다.
기준 3. 패키지 하나. 항목을 낱개로 팔지 않고 묶어서 한 상품. 프리미엄은 하나이며 축(창업준비→사장님→양도인)을 따라 내용이 바뀐다(PRICING §3-c 확장).
프리미엄이 파는 것은 세 종류뿐: 공식 자료 / 모두가 직접 본 것 / 본인이 넣은 값으로 돌아가는 도구. 양도인이 적은 값은 "양도인이 적은 값" 라벨로 옆에 놓일 뿐이다.
2. 재료 — 3층 구조 (3차 안, 대표 "시행은 하되 지금은 아님")
1층. 자리 공식 자료 한 장 — "이 주소에 대해 나라가 알고 있는 것"
인허가 기록 — 행정안전부 지방행정인허가데이터(전국 일반음식점 표준데이터 약 213만 건, 2일 단위 갱신, 무료·이용 제한 없음, 휴게음식점·미용·학원 등 업종별 파일 별도). 이 주소의 개업·폐업 횟수·시기·업태. ※ 9/9 폐기한 B-5(사용자 작성 후기·시간순 이력)와 성격이 다름 — 정부 원장. 대표 판단 대기.
건축물대장 — 주용도·전용면적·사용승인일·위반건축물 표기·집합건물 여부(오더 2026-09-11 파트 B로 확보). 등록 면적과 다르면 두 값 나란히.
부동산원 임대동향 — 상권 공실률·㎡당 임대료 vs 이 매물 월세(오더 파트 A).
국토부 상업·업무용 실거래 — 반경 내 12개월 매매·임대 실거래 목록(기존 파이프라인).
소진공 상가정보 — 반경 200m 같은 업종 업소 수·최근 4분기 증감.
교육환경보호구역·용도지역 — 구역 안/밖 사실만, 업종 가능 여부 판정 없음, 관할 링크.
무료: 각 항목을 정부 사이트 링크로. 프리미엄: 주소 하나로 한 장, 등록값과 나란히, 저장·비교. 파는 건 "모아 주는 시간".
2층. 모두가 직접 본 것 — 플랫폼 관측 로그
등록 경과일 / 권리금·월세 변동 이력(횟수·날짜·값) / 등록 정보 수정 이력(횟수·날짜만) / 찜 추이·문의 수(표본 임계값 이상) / 양도인 평균 답장 시간 / 재등록 여부(거래 완료 후 90일 내 같은 주소 재등록) / 건물 교차(같은 주소가 소유주 축 매각 매물인지, 같은 건물 다른 호실 양도 매물 수).
무료: 현재가·찜 배지. 프리미엄: 전부.
3층. 본인이 넣어서 본인이 판단하는 도구
임장 카운터 — 매장 앞 시간대별 손님 수 탭, 객단가 본인 입력, 여러 날 합산. (40~60대가 실제로 쓸지 대표 판단 대기)
손익 계산기 — 등록 월세·관리비 + 업종별 비용 비율 공개 통계(출처·연도 표기) + 본인 추정 매출 → 손에 남는 돈·손익분기. "가정을 바꾸면 결과가 바뀌어요 · 모두가 보장하는 숫자가 아니에요".
동네 비교표 — 관심 동 같은 업종 매물 전부, 1·2층 항목이 열. 프랜차이즈는 공정위 정보공개서 공개 수치 열.
진행 관리 — 방문 일정 제안(일정 알림 연결), 방문 체크리스트, 계약 전 체크리스트, 업종별 인허가 절차, 자금 계획 시트.
무료: 계산기 합계, 체크리스트 5항목, 방문 제안 월 N건. 프리미엄: 전부 + 매물 5개 같은 가정으로 비교.
3. 검토 때 더 볼 혜택 후보 (미검토 — 패키지 묶을 때 하나씩 판단)
창업 후 이어지는 혜택: 사장님 축 전환 시 매출 리포트·시세 카드가 같은 구독으로 계속(전환 유지율 지표).
기업회원 서비스 묶음: 세무·인테리어·간판 등 입점 업체의 "모두 구독자 첫 상담 무료" 같은 혜택 — 업체가 자발적으로 거는 것만, 모두가 비용 부담 없음, 순서·노출과 무관(§1-1).
계약 단계 도구: 임대차·권리금 계약서 템플릿(계약서 앱과 통일), 잔금 전 체크리스트.
정부 지원 안내 묶음: 창업안심정책보험(2027)·희망리턴패키지·정책자금 링크(B-2·B-8과 연결, 정부 사이트로만).
보상 프리미엄: 방문 결과 칩·계약 완료 칩·프로필 조건 완성 → 기간 보상(§3-b). 후기·자유 텍스트 없음.
무료 체험·요금 수준: §5 대표 확정 항목.
창업준비 '우선순위 1개' 온보딩(지시문/준비/창업준비_우선순위1개)과 묶어 "프로필 조건 → 맞춤 한 장"으로 이어지는 흐름.
행사 탭(B-1)의 참석 우선권은 넣지 않는다 — 순서·우선권 판매 금지 원칙과 충돌.
4. 책임 선 — 프리미엄뿐 아니라 지금부터 모든 화면에 적용 (방향 원칙)
화면의 모든 수치에 출처 라벨 4종 중 하나: "공식 자료(기관·기준일)" / "모두가 본 것(기록일)" / "양도인이 적은 값" / "내가 넣은 값". 라벨 없는 숫자는 못 나간다.
"확인됨·검증·인증·믿을 수 있는·안전한" 단어 금지. 카드매출 연동은 "연동된 카드매출 기준 · 현금 매출 미포함"으로만.
판정 문구 금지(좋다·나쁘다·위험하다·부풀려졌다). 사실 두 개를 나란히 놓는 것까지가 모두의 일.
등록값이 공식 자료와 다를 때 양도인에게도 같은 화면("대장 면적과 달라요 · 확인해 주세요"). 창업준비자에게만 보여주고 양도인에게 숨기지 않는다.
프리미엄 화면 상단 고정 1줄 "공공 자료와 모두가 기록한 것을 모아 드려요 · 판단은 직접 하세요". 이용약관에 같은 문장.
5. 검토 시점 (이 중 하나면 대표에게 상기)
Claude Code: 요금제·plan_tier·premium·quota 코드, 창업준비 축 화면(탐색·매물 상세·내 관심·비교), PRICING §3을 만지기 시작할 때.
채팅(매월 1일 확인 작업): 창업준비 프로필 300개 또는 매물 평균 찜 5건 도달 시 — '우선순위 1개' 온보딩과 같은 시점에 이 패키지 검토도 함께 안내.
대표가 "창업준비 구독" 또는 "프리미엄 패키지"를 언급할 때.
6. 확정 대기 항목
1층 1(정부 인허가 기록)을 B-5와 별개로 볼지 / 3층 1(임장 카운터) 채택 여부 / 패키지 최종 구성·요금·무료 체험(§5) / 확정 시 PRICING §3을 축별 표로 개정하고 오더 작성.
