# [ORDER-e1p-facility-v1] 임대인 시설 현황 입력 — 공실 상태 + 잔존 설비 + 건물 설비

■ 모드: 자율 판정. 멈춤 (a)스키마 SQL (b)실DB 정정 (c)판정 불가만. 장치 3 의무.

## 1. 빈 섹션 탭 수정 (선행)
E2L 섹션 탭이 내용 없는 섹션을 노출하지 않도록 규칙 적용 + 전 섹션 전수 점검. E2 동일 확인.

## 2. E1p 시설 현황 단계
a. 내부 상태 (필수 칩 2택): 공실이에요 / 설비·집기가 남아 있어요
   — occupancy(임차 계약 관점)와 분리: interior_state(물리 상태).
b. 잔존 설비 (설비 있음일 때만, 다중 칩): 주방 설비/냉난방기/인테리어/테이블·의자/간판/
   카운터·POS 자리/덕트·후드/화장실 내부/기타 직접입력 + 이전 업종(IndustryPicker).
c. 건물 설비 (무관, 다중 칩): 엘리베이터/주차장/화장실 전용·공용/냉난방 중앙공급/
   전기 승압 가능/가스 인입/정화조 여유/급배수.
d. 저장: 스키마 SQL 제시 후 멈춤(a) — 새 헌법 규칙대로 push는 SQL 확인 후.
   payload↔역매핑 자동 대조로 복원 검증 + 왕복 보존.
e. 컴포넌트: 재사용 판정 후 공용 추출 (복제 금지).

## 3. 시설 블록 생성 반영
서술형·공실=자유도·잔존=투자 절감·건물 설비=사실 기반. 재료 없으면 블록·탭 생략.
