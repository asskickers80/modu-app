# 모두(Modu) — 브랜드·어휘 단일 소스 (BRAND.md)

이 문서가 정체성·카피·어휘 규칙의 **단일 소스**다. 다른 문서에 같은 규칙이 보이면 이 파일을 가리키게 하고, 값을 양쪽에 두지 않는다.
변경은 **대표 지시로만** 가능하다.

## 정체성 (확정)

모두는 대한민국 리테일 생태계를 잇는 플랫폼이다.
이 정의는 앱·웹(modu-web) 양쪽의 공통 기준이며, 변경은 대표 지시로만 가능하다.

## 카피 세트 (확정)

| 자리 | 문구 |
|---|---|
| 메인 히어로 | 리테일 생태계, 모두 여기에 |
| 히어로 보조 | 시작하는 사람도, 넘기는 사람도, 돕는 사람도 |
| 회사 소개 첫 줄 | 모두는 대한민국 리테일 생태계를 잇는 플랫폼입니다 |
| 투자자 자료 | 대한민국 리테일 생태계 인프라 |
| 사장님 대면 | 혼자 알아보지 마세요. 모두가 다 알아봐 드립니다 |

부호 없는 변형 "리테일 생태계 모두 여기에"도 로고 병기 자리에서 허용한다.

## 언어 분리 원칙 (중요)

"리테일", "생태계", "플랫폼", "인프라"는 **대외 언어**다.
사장님·양도인·소유주·창업준비자가 보는 앱 화면에서는 쓰지 않는다.
사용자 대면 문안은 기존 모두 화법을 그대로 유지한다.

**허용되는 자리**
- 설정 > 서비스 소개
- 이용약관·개인정보처리방침 머리말
- 앱스토어 설명
- 외부 공유 메타 태그(og:description)

**금지되는 자리**
- 온보딩, 홈, 등록, 매물 상세, 알림, 카드 문구, 빈 상태 문구 등 **사용자 대면 전 화면**

이 분리는 `scripts/lint-brand.mjs`(= `npm run lint`)와 `tests/brand-copy.spec.js`가 자동으로 지킨다. 허용 자리는 그 스크립트의 예외 목록 한 곳에만 둔다.

## 어휘 규칙 (축별 — 통합)

| 축 | 쓰는 말 | 쓰지 않는 말 |
|---|---|---|
| 양도인 | 매물 · 권리금 · 동향 | "가게" |
| 소유주(임대인) | 상가 · 매매가 · 임대료 · 시세 | "가게" |
| 사장님(운영 중) | **가게** 허용 · 매출 | — |
| 창업 준비 | 매물 · 점포 | "가게" |
| 기업회원 | 업체 · 입점 · 문의 | "제휴", "연동 계약", "매물 공급처" |

- **"AI" 라벨 금지** — 화면 문안 어디에도 "AI"라는 단어를 쓰지 않는다. 기능 이름은 '모두에 질문하기'처럼 하는 일로 부른다.
- **판단 문구 금지** — "비싸요 · 싸요 · 좋은 자리 · 잘 될 거예요" 같은 평가. 사실 두 개를 나란히 놓는 것까지가 모두의 일이다.
- **효능 약속 금지** — "N배 늘어요", "지원금 받으세요", "지금 해지하면 손해" 류.
- **평점·별점·추천·인증·검증 금지** — 후기·한마디·업체 화면(2026-09-12 결정).
- **성사 약속·문의 품질 평가 금지** — "문의로 만들어드릴게요", "진성 문의" 류(2026-09-13 결정).
- **(예정) 표기 유지** — 인프라가 없어 아직 동작하지 않는 자리는 틀을 남기고 `(예정)`으로 표시한다. 동작하는 것처럼 위장하지 않는다.
- **출처 라벨 4종** — 화면의 모든 수치에는 "공식 자료(기관·기준일) / 모두가 본 것(기록일) / 양도인이 적은 값 / 내가 넣은 값" 중 하나가 붙는다. 라벨 없는 숫자는 만들지 않는다.
- **표본 미달이면 숨긴다** — 가짜 숫자·더미 표시 금지(PRICING §1-2).

## 로고 자산 (2026-09-14 확정본)

**원본은 한 장이다** — `docs/brand/logo.png` (가로형 락업 1070×550, 흰 배경 포함). 이 파일은 수정하지 않는다.
나머지 크기·색은 전부 여기서 파생한다: `node scripts/gen-brand-assets.mjs`

| 파생 자산 | 쓰는 자리 |
|---|---|
| `public/brand/logo.png` (원본 그대로) | 로딩 D · 흰 배경 위 가로형 |
| `public/brand/logo-transparent.png` | 파란 배경 위 가로형(A2 등) |
| `public/brand/logo-white.png` | 파란·남색 배경 위 가로형(스플래시·A2) — 남색 워드마크가 묻히는 자리 |
| `public/brand/symbol.png` | 심볼만 — 헤더 버튼·워터마크 |
| `public/brand/symbol-{white,seller,landlord,operating,business,browsing,brand}.png` | 역할색 동그라미 안·작은 자리·파비콘 |
| `public/icon-512/192.png` · `apple-touch-icon.png` · `favicon-32.png` | 앱 아이콘(정사각, 심볼만, 여백 10%) |

배경 제거는 **테두리에서 이어진 흰색만** 지운다(안쪽 광택 보존). 연한 하늘색 구슬은 채도 검사로 보호한다.

### 로고만 / 로고+글자 자리 구분

| 들어갈 것 | 자리 |
|---|---|
| **가로형(심볼+글자)** | 첫 진입 스플래시 · 전체 화면 로딩 · A2 상단 · A6 환영 · 외부 공유 이미지 · 설정>서비스 소개(생기면) |
| **심볼만** | 홈 헤더 버튼 · 마이 · 커뮤니티 · 탐색 워터마크 · 앱 아이콘 · 파비콘 |
| **심볼 실루엣(단색)** | 역할색 동그라미 안 카드 말풍선(15~18px) · 16px 파비콘 |
| **기존 심볼 스피너 유지** | 등록·채팅·사진 업로드의 작은 인라인 로딩(28~72px) — 글자를 넣을 자리가 아니다 |

로딩 D는 디자이너 확정본(`src/styles/modu-d.css`)을 그대로 이식했다. **원본 PNG는 손대지 않고 그 위 빛줄기만 움직인다.**
기기에서 '동작 줄이기'를 켜면 빛줄기는 멈추고 로딩 표시는 남는다.
