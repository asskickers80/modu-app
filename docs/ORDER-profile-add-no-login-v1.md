# [ORDER-profile-add-no-login-v1] 로그인 상태 프로필 추가 시 로그인 화면 재요구 제거

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.

## 증상 (실기기)
로그인 상태에서 프로필 추가 → A2에서 사장님(운영중) 선택 → A3 업종·지역 응답 완료
→ 그런데 로그인 화면(A4)이 다시 나타남. 이미 로그인된 계정인데 재로그인 요구.

## 원칙 (IDENTITY-MODEL 기준)
로그인 상태에서의 역할 추가는 인증 절차 없이 즉시 완료. A3 응답이 끝나면
바로 roles에 추가(서버 저장) → 해당 프로필 홈으로 진입.

## 수정
1. 온보딩 종료 분기: user 존재 → A4 우회, roles 합집합 갱신 후 해당 축 홈으로 이동.
   user 부재 → 현행(A4 가입·로그인) 유지.
2. A3 응답(업종·지역 등)이 새 프로필에 정상 저장되는지 확인 — 축별 프로필 데이터가
   기존 역할 정보를 덮지 않을 것 (역할별로 분리 저장되는 구조인지 점검, 문제 있으면 보고).
3. 경로 매트릭스 재점검: (+) 버튼 / A2부터 밟기 / A3 직접 진입 — 세 경로 모두
   로그인 상태에서 A4를 거치지 않는지 테스트로 고정.
   (identity-model 때 경로 매트릭스를 만들었으나 "로그인 상태 추가" 경로가
   빠져 있었는지 확인 후 정직 보고)
4. 진입 후 활성 프로필이 방금 추가한 축인지 확인.

## 테스트
로그인 상태 3경로 × A4 미노출·roles 합집합·활성 전환. 비로그인 경로 회귀. 전체 스위트.

## 보고
4줄(ls-remote) + 경로 매트릭스 누락 여부 정직 보고 + A3 응답 저장 구조 점검 결과.
