# ORDER-auth-loop-fix-v1 — 뒤로가기 카카오 로그인 무한 루프 (치명)

## 증상 (실기기)
E2L 진입 → 뒤로가기 → 카카오 로그인 리다이렉트 무한 반복.

## 조사 (수정 전 원인 보고)
1. 리다이렉트 발원지 특정 — 유력: 세션 로딩 전 user=null 오판 가드.
2. 루프 성립 경로(히스토리 스택에 인증 URL 축적 방식 포함).
3. 동일 "로딩 미대기 가드" 패턴 전수 grep.

## 수정 원칙
인증 가드 3상태(로딩/로그인/비로그인). 로딩 중 리다이렉트 금지. 비로그인 확정 시에만. 인증 복귀 history replace로 스택 오염 방지.

## 안정화 계층
실기기 생존 시나리오 셋(강제 리로드/뒤로가기/앱 전환 복귀) — 수정 모드 URL 보존 계열 통합.
