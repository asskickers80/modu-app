# [ORDER-weekly-one-liner-v1] "이번 주 한 줄" 카드 — 사장님·양도인 홈

■ 저장 지시: docs/ORDER-weekly-one-liner-v1.md 저장.
■ 모드: 자율 판정. 멈춤 (a)(b)(c)만. 장치 3(양도인 diff 요약) 의무.
■ 원칙: 신호 선별 전부 룰, 문장 고정 템플릿. AI 호출 없음. 신호 없으면 카드 미표시
   (빈 카드·"데이터 부족" 금지). 어휘: 양도인=동향/매물, "가게" 금지.

■ 배치·공존 (대표 결정: (나))
사장님 홈 = 매출 카드 아래, 양도인 홈 = 문의 동향 카드 위. 기존 "오늘의 한 마디"와
공존: 이번 주 신호가 있으면 한 줄 카드 표시 + 한 마디 숨김, 신호 없으면 한 마디만.
같은 위치에 둘이 동시에 그려지지 않음.

■ 배치 계산
매주 월요일 06:00 KST 크론(기존 Vercel Cron 패턴) → weekly_one_liners 테이블에 저장
(id, user_id, role, week_start, signal_key, headline, evidence, cta_key, cta_payload jsonb,
computed_at, dismissed_at). 홈은 저장값만 읽음. 스키마 SQL(a).
신호는 위에서부터 검사, 처음 걸리는 1개만.

■ 사장님 신호 (daily_sales 기준, 최근 8주 중 입력 주 ≥4일 때만 계산)
1. weekday_drop3: 같은 요일 3주 연속 하락 → "{요일}요일 매출이 3주째 내려가고 있어요" /
   "{3주 전} → {지난주}" / [이번 주 매출 입력]
2. month_drop20: 이번 달 누적이 전월 같은 날짜 누적 대비 -20% 이하 → "이번 달이 지난달보다
   {p}% 적어요" / 근거 두 수치 / [메모 남기기](매출 메모 기능)
3. month_up20: +20% 이상 → "이번 달이 지난달보다 {p}% 많아요" / [매출 그래프 보기]
4. best_day: 최근 4주 요일 평균 최고/최저 ≥1.5배 → "{최고요일}이 {최저요일}보다 {배수}배
   팔려요" / "최근 4주 평균" / [매출 그래프 보기]
5. missing_input: 최근 7일 중 미입력 ≥3일 → "지난주 {n}일치 매출이 비어 있어요" /
   "입력한 주만 비교가 돼요" / [지금 입력]
6. lease_end_90: roleData.operating.lease_end_date ≤90일 → "임대차 만료까지 {d}일
   남았어요" / "갱신 요구는 만료 6개월~1개월 전" / [양도 준비 알아보기] → 양도인 프로필
   없으면 양도인 온보딩 진입(A3 직행, 승계 확인 경유), 있으면 양도인 홈.
   ※ "양도 시세 보기" 문구 금지(어휘 규칙·데이터 부재).

■ 양도인 신호 (문의 원장 기준)
1. inquiry_topic: 최근 14일 문의 ≥3건, 첫 메시지 키워드 분류 최빈 주제 ≥40% →
   "최근 2주 문의 {n}건, {주제} 질문이 제일 많았어요" / "{주제} 정보를 매물에 적어두면
   문의가 줄고 계약이 빨라져요" / [매물에 {주제} 추가] → E1 해당 단계 수정 진입.
   키워드표: docs/inquiry-topic-keywords.md (대표 제공 예정 — 아래 초안으로 시작).
2. fav_no_inquiry: 관심(찜) 기능 미구현 → 이번 범위 제외, 코드에 (관심 기능 후 활성)
   주석과 스텁만.
3. inquiry_unanswered: 새 문의 강조 타일과 중복 → 제외.
4. no_inquiry_14: 문의 동향 카드 승격 룰과 중복 → 제외.
   → 현재 양도인 실신호는 inquiry_topic 1개. 없으면 한 마디 표시.

■ UI: 카드 헤더 ModuWord "모두" + "이번 주 한 줄". 문장 1줄 + 근거 1줄 + 버튼 1개.
   우상단 X → dismissed_at, 그 주 숨김(한 마디로 대체 표시).
■ 이벤트(events 테이블): one_liner_shown(signal_key, role), one_liner_cta(signal_key),
   one_liner_dismissed(signal_key), one_liner_none(role).
■ 테스트: 요일 3주 하락 데이터 → 1번 채택(2번 동시 참이어도 1개) / 입력 3주뿐 → 카드 없음
   +한 마디 표시 / 문의 5건 중 권리금 3건 → inquiry_topic "권리금" / X → 같은 주 미표시 /
   두 축 사용자 → 각 홈 각자 신호. 전체 스위트.
