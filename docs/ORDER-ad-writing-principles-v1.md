# [ORDER-ad-writing-principles-v1] 매물 광고 작성 원칙 — 블록별 집필 규칙 (프롬프트 헌법)

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.
■ 관계: ad-frame-v1의 카테고리 구조 위에 각 블록의 집필 원칙을 정의.
   프롬프트는 lib/adWritingPrinciples 상수로 분리 — 원칙 수정 시 한 곳. 장치 3 의무.

## 양도인(E1) 블록별 집필 원칙 (대표 확정)
- **매물 개요**: 면적·층·시설 연차·매출과 수익·프랜차이즈 여부를 한 단락 요약.
  상세 블록의 예고편 — 깊이 들어가지 않는다.
- **영업**: 매출·수익이 있으면 수치 기반. 없으면 상권 실값 근거로 "정상 운영" 수준
  간략 서술만 — 수치 추정·날조 금지, 짧아도 됨.
- **시설**: 입력 시설을 최대한 반영하되 나열이 아닌 서술형 자연문.
  연차 톤 분기: 1년 내외=새것에 가까움 / 5년 이상=정상 운영 가능하게 유지관리.
  "추정됩니다" 남발 금지. 화면 시설 목록(불릿)은 별개 유지 — 서술은 종합.
- **상권 및 입지**: 가장 공들이는 블록. 소진공 실값 + 좁은 반경 자리 특성 + 층·접면·주차
  칩 + 그라운딩 확인 사실. 실값 인용을 아끼지 않는다. 날조 금지는 동일.

## 임대인(E1p) — 동등 수준, 임대차·매매 관점
[상가 개요] 면적·층·거래유형·가격 조건·임차 현황 요약.
[거래 조건] 임대=임차인 관점 / 매각=매수자 관점(수익률·투자 판단). 실계약/예상 구분 유지.
[시설·건물] 서술형 동일 원칙(건물 상태·설비·연차).
[상권 및 입지] 양도인과 동일 밀도.

## 공통 규칙
- 블록당 3~4문장 기준, 사실 부족 시 짧게(분량 위해 날조 금지).
- 확인 사실=구체 인용 / 미확인=정성 서술 또는 침묵.
- 모두 화법, 과장·보장 표현 금지(등록 확인사항 4조와 정합).
- 흩어진 규칙을 이 상수로 통합 — 중복·충돌 정리 보고.

## 검증
실출력 4건: 양도인(매출 있음/없음) + 임대인(임대/매각). 블록별 원칙 준수 표시.
시설 서술형 전환·연차 톤 분기 확인.
