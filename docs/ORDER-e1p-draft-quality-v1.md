# ORDER-e1p-draft-quality-v1 — 상가 설명문 품질 강화 + 단계 통합 (초안·검수 1단계화)

## 모드: 자율 판정. 멈춤 (a)스키마 SQL (b)실DB 정정 (c)판정 불가만.

## 배경 (대표 지적)
설명문·위치·상권 부실(하드코딩 더미 혼재). 권장업종 별도 블록 파편화. 소개글→검수 단계 분리(양도인은 1화면 원칙 기확정).

## 1. 설명문 품질 — 근거 기반 리치 초안
필수 요소(근거 있는 내용만): 추천 업종(본문 포함)·유동인구·배후세대·상권 특성.
a. Gemini 검색 그라운딩(Google Search) 활성화 — 주소·상권 실제 검색 근거로 작성. 근거 없으면 일반론 채우기 금지(수치 날조 금지 유지). ※ Gemini 호출 비용·지연 증가 — 보고 명시.
b. 공공 상권 데이터(소진공 상권정보 등) 유동인구·배후세대 실값 결합 검토 — 키 필요 시 절차 안내 후 그 부분 (예정).
c. 하드코딩 더미 전부 제거(위치·상권 고정 문구, 시세 폴백 가짜 범위) — 근거 없으면 생략.
- 학습 기반: ai_draft(원문)+edited_texts(수정) 저장 확인·정비(스키마 필요 시 a). 학습 루프 구현은 범위 밖.

## 2. 권장업종 블록 통합
별도 블록 삭제 → 설명문 본문에 포함. Step1 '선호 업종' 입력 유지(프롬프트 반영). E2L 칩 유지 여부 자율(recommended_biz 저장 유지).

## 3. 단계 통합 — 초안·검수 1화면 (E1 준용)
E1p 5→4단계: ①기본 정보 ②소개글(초안+블록별 검수·수정 1화면, E1Step2 구조 준용·공용화 검토) ③도면·사진 ④저장·공개.
Step3 검수 기능(유지/수정/비공개)은 ②로 흡수 — 기능 소실 금지. 라우트·EditStepTabs·ProgressBar·가이드 딥링크·테스트 정합. 수정 모드 원칙(편집 기본·극장 금지·URL 보존) 유지.

## 테스트: 리치 초안(그라운딩 mock)·더미 부재·업종 본문 포함·4단계 완주·검수 보존·수정 회귀. 전체.
