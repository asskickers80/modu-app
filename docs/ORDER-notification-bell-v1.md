# [ORDER-notification-bell-v1] 알림 벨 전 축 배치 — 모두 발송 알림 전용

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.
■ 장치 3(양도인 diff 요약) 의무.

## 결정 (대표 확정)
설정 톱니는 제거 유지(마이 탭 중복). 알림 벨은 전 축 헤더에 배치.
벨의 성격 = "모두(플랫폼)가 사용자에게 보내는 알림" 전용.
사용자 간 활동(새 문의·답장·안읽은 메시지)은 벨에 표시하지 않는다 —
그것들은 메시지 탭·홈 지표가 담당하며, 중복 표시 금지.

## 1. 배치
HomeHeaderBar 공용 컴포넌트에 알림 벨 추가 → 5축 동시 적용. 축별 개별 구현 금지.

## 2. 신호 규칙
- 상시 빨간 점 하드코딩 금지 (기존 위반 사항 제거 유지).
- 모두 발송 알림이 미확인 상태일 때만 UnreadDot 표시.
- 현재 모두 발송 알림 이벤트가 0개이므로 기본은 점 없는 벨.

## 3. 탭 동작
알림 센터 미구현이므로 (예정) 안내: "알림 센터는 준비 중이에요" +
사용자 활동은 어디서 보는지 안내("새 문의는 메시지 탭에서 확인할 수 있어요").
향후 알림 센터 구현 시 이 지점만 라우팅 교체하도록 구조 정리 + 주석.

## 4. 알림 센터 설계 메모 (문서만, 구현 아님)
docs/에 향후 "모두 발송" 알림 이벤트 후보 기록:
- 폐업 확인 요청 (국세청 배치 감지)
- 일정 알림 (임대료·부가세 등 역산 파생 — 일정관리 로드맵)
- 매칭 제안 (AI 매칭 고도화)
- 시세·상권 변동 알림 (인근 실거래 신고 감지)
- 공지·정책 변경
※ 사용자 간 활동은 이 목록에 포함하지 않음.
일정관리·매칭 로드맵과 도메인 규칙표를 공유하게 됨을 명시.

## 테스트
5축 벨 존재, 가짜 점 부재, 탭 시 (예정) 안내, 톱니 부재. 전체 스위트.
