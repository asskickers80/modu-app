# ORDER-vacancy-word-cleanup-v1 — "공실" 어휘 정리 (사용자 언어는 임대/매매)

## 원칙
사용자 노출 문구에서 "공실" 미사용. 사용자 언어 = 임대(임차인 맞추기)/매매(팔기) 두 축.
occupancy는 내부 데이터·계산 재료로 존속(수익률/예상 구분).

## 교체
1. E1p 임차 현황 칩: "공실이에요" → "없어요".
2. E2L 기준 안내: "공실·예상 시세 기준" → "예상 시세 기준".
3. 전 축 grep: 사용자 노출 "공실" 전수 목록화 후 교체. 배치 콘텐츠 본문의 "공실"(예: "공실 대응")은 일반 부동산 용어라 허용, UI 라벨·상태 표기의 "공실"만 금지 — 경계 판정 근거 보고.
4. 내부 코드(occupancy 'vacant', 변수명) 무변경.

## 테스트: 칩 라벨·기준 안내 교체 확인. 전체.
