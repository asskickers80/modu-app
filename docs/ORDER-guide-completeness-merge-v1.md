# [ORDER-guide-completeness-merge-v1] 진행 가이드 + 완성도 통합 (양도인·임대인 공통)

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.
■ 장치 3(양도인 diff 요약) 의무.

## 배경 (대표 확정)
진행 가이드와 완성도 카드가 사실상 같은 일("뭘 더 채우면 좋은지")을 두 카드에서
하고 있음. 하나로 통합한다. 완성도 카드가 가이드의 접힌 얼굴이 된다.

## 통합 구조 (B안)
- 미완료 단계 존재 → 펼침 = 진행 가이드 (현행 단계 목록·체크·탭 진입 유지).
- 등록 관련 단계 전부 완료 → 접힘 = 완성도 표시:
  퍼센트 + 게이지 + 다음 액션 힌트 + 거래 상태 한 줄(기구현 3분기 문구:
  "문의를 기다리는 중" / "문의 N건 · 답장을 기다리는 중" / "문의 N건 · 협의 진행 중").
- 접힌 상태 탭 → 펼침 (가이드 전체 열람). 펼침 상태에서도 완성도 퍼센트는
  헤더에 유지 판정 자율 (중복 아니면 유지, 산만하면 생략 — 근거 보고).
- 기존 별도 완성도 카드는 제거 (통합 후 중복 금지).

## 위치
통합 카드는 기존 가이드 자리(홈 상단부, 객체 카드 아래) 유지. 완성도 카드가 있던
하단 자리는 비움 — 홈 블록 순서 재정렬 필요 시 판정 자율, 양축 동일하게.

## 복수 객체 처리
임대인 복수 상가: 완성도는 최저 상가 기준 표시(기구현 정책 유지), 가이드도 같은
기준 상가로 통일. 어느 상가 기준인지 라벨 명시(기구현).

## 테스트
미완료 펼침 / 완료 접힘+완성도 표시 / 토글 / 3분기 문구 / 별도 완성도 카드 부재 /
양축 동일. 전체 스위트.
