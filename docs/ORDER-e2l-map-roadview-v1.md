# ORDER-e2l-map-roadview-v1 — E2L 지도·거리뷰 (네이버 지도 API, 공개 opt-in)

## 모드: 자율 판정. 멈춤 (a)스키마 SQL (b)실DB 정정 (c)판정 불가.

## 선행 (대표 실행 — Code가 절차 안내)
NCP 가입 → Maps 신청(Web Dynamic Map + 파노라마) → 클라이언트 ID 발급 → 요금·무료쿼터 확인 → env 주입(Vercel env). 키 전 가능 작업(컴포넌트·스키마·opt-in) 먼저.

## 1. 공용 컴포넌트 components/MapPanel
주소/좌표 → 지도 + "거리뷰" 탭. 기본 지도, 거리뷰 탭 시 파노라마 lazy load(쿼터 절약). 미커버 폴백("이 위치는 거리뷰가 제공되지 않아요")+지도 유지. 축 무관(props: 좌표·공개여부).

## 2. 좌표
지오코딩(네이버) 등록/수정 시 1회 변환·저장(표시 때마다 호출 금지). 좌표 컬럼 SQL(a). 기존 상가 백필 방안 포함.

## 3. opt-in
E1p 공개 단계 "지도·거리뷰 공개" 칩 2택, 기본 ON. 끄면 E2L 지도 미표시. show_map 컬럼 SQL. 수정 모드 토글 가능.

## 4. E2L 표시
공개 ON 상가에 MapPanel(위치 섹션). 소유자·방문자 동일. 로드 실패 시 정직 폴백(빈 회색 박스 금지).

## 5. 양도인 확장은 범위 밖 — MapPanel 재사용 가능 상태까지.

## 테스트: opt-in ON/OFF·거리뷰 탭·미커버 폴백·지오코딩 저장. 키 없는 로컬 모킹. 전체.
