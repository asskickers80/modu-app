# [ORDER-listing-duplicate-fix-v1] 매물 복제 등록 — 데이터 무결성 (급함)

■ 모드: 자율 판정. 멈춤 (a)(b)(c)만.

## 증상
임대인 상가 1건 임대 등록 → listings 2행. 양도인 홈에도 노출 + 업종 재확인 요구.

## 원인 (조사 결과)
- 두 행 모두 landlord, 같은 값, created_at 0.57초 차이 → (다) 저장 중복 호출.
- E1p 공개 성공 화면 "대시보드로 이동" = 저장 실행 버튼, 재진입 가드 없음.
  더블탭이 지오코딩 await 사이에 끼면 INSERT 2회.
- 양도인 홈 노출은 별개 결함: 홈 조회에 listing_type 필터 부재.

## 수정
- E1p 저장 재진입 가드(savingRef) + 버튼 비활성·저장 중 표시.
- 양도인 홈 조회 .eq('listing_type','seller') — 홈은 자기 축 매물만.
- 원칙: 매물은 하나, 노출은 여럿. 임대 매물의 탐색 노출은 별도 안건 보류.

## 기존 복제 정리
쌍 2건: 수원(정정 SQL — 업종 채워진 최신 행 보존) / 영종(한쪽 이미 deleted, 조치 불요).
복제 행에 대화 연결 없음.
