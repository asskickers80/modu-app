# 모두 — 실기기 테스트 따라하기

9월에 만든 기능을 **1번부터 차례대로** 확인하는 문서입니다. 위에서 아래로 그대로 따라 하시면 됩니다.
각 번호마다 **어느 기기에서 · 어느 화면에서 · 무엇을 누르는지**를 적었고, 마지막 줄 ✅ 가 그대로 보이면 통과입니다.
다르면 그 번호와 화면 사진만 남겨 두시고 다음 번호로 넘어가시면 됩니다.

전체 49번, 넉넉히 잡아 4시간 30분입니다. 한 번에 다 하실 필요 없습니다 — 1~15번(휴대폰만), 16~24번(두 기기), 25~32번, 33~46번, 47~49번으로 끊어서 하셔도 앞뒤가 맞습니다.

## 준비 (15분)

**ㄱ. 두 기기를 준비합니다.**

| 기기 | 이 문서에서 부르는 이름 | 역할 | 계정 |
|---|---|---|---|
| 평소 쓰시는 휴대폰 | **휴대폰** | 사장님 · 양도인 · 기업회원 | 대표님 본 계정 |
| 컴퓨터 브라우저(시크릿 창) | **컴퓨터** | 가게를 찾는 손님(창업 준비) | **다른 테스트 계정** |

컴퓨터에서 대표님 본 계정으로 로그인하시면 안 됩니다. 같은 사람으로 합쳐져서 "찜한 사람" 역할이 되지 못합니다.

**ㄴ. 두 기기 모두 아래 주소로 엽니다.** 다른 주소로 들어가면 카카오 로그인이 막힙니다.

```
https://modu-app-asskickers80s-projects.vercel.app
```

**ㄷ. 휴대폰**: 아래 탭 **마이**에 `🟡 로그인됨`이 보이는지 확인합니다.

**ㄹ. 컴퓨터**: 시크릿 창에서 위 주소 → 카테고리 고르는 화면에서 **창업 준비** → 질문 3개는 아무거나 → 네이버나 카카오로 **테스트 계정** 로그인.

**ㅁ. 컴퓨터에 SQL 편집기를 하나 더 띄워 둡니다.** Supabase 에서 주소에 `edcqvmgqskeoegpqxlzy` 가 들어간 프로젝트를 고르고 SQL 편집기를 엽니다. 다른 프로젝트를 고르면 "테이블이 없다"는 오류가 납니다.

첫 줄로 아래 한 줄만 실행해 둡니다(이미 들어가 있어도 다시 실행해서 문제 없습니다).

```sql
alter table inquiry_ledger add column if not exists region text;
```

**ㅂ. 판정 요령 세 가지**
- "안 보이는 게 정상"인 항목이 많습니다. 가짜 숫자·빈 카드를 만들지 않는 것이 원칙이라, 자료가 모자라면 화면이 조용히 비어 있습니다.
- 두 기기를 오갈 때는 **새로고침**해야 상대가 한 일이 보입니다.
- 화면에 **"AI"** 라는 글자가 보이면 그것만으로 실패입니다(문구 규칙).

# 1부. 휴대폰 혼자 (1~15번, 약 1시간 20분)

## 1. 역할별 홈과 아래 탭 (휴대폰)

1. 홈 화면 위쪽의 **동그란 역할 칩**(예: 양도인)을 누릅니다.
2. 올라온 목록에서 다른 역할을 골라 그 홈으로 갑니다. 갖고 계신 역할을 하나씩 다 돌아 봅니다.
3. 각 홈에서 아래 탭 **홈 · 탐색 · 커뮤니티 · 메시지 · 마이**를 왼쪽부터 차례로 눌러 봅니다.

✅ 어느 역할이든 탭 5개가 같은 자리에 있고, 지금 있는 탭 글씨가 역할 색으로 칠해집니다(양도인 남색 · 소유주 청록 · 사장님 초록 · 기업회원 보라). 빈 화면이나 깜빡임이 없어야 합니다.

## 2. 사장님 역할 준비 (휴대폰)

사장님 역할이 이미 있으시면 3번으로 건너뜁니다.

1. 역할 칩 → **역할 추가** → **운영 중(사장님)**.
2. 질문 3개에 답합니다. **지역은 서울 마포구, 업종은 카페·베이커리 계열**로 골라 주세요. 뒤에서 넣을 시험 데이터와 맞춰야 합니다.

✅ 초록색 사장님 홈이 열립니다.

## 3. 오늘 매출 입력 (휴대폰)

1. 사장님 홈 맨 위 **오늘 매출** 카드 → **[입력]**.
2. 날짜 칩 첫 칸이 **오늘**인지 봅니다(그 옆이 어제 … 7일 전).
3. **+10만** 버튼을 한 번 누르고 **저장**.

✅ 카드에 `100,000원`, 아래에 "오늘 매출 10만원 저장했어요 ✓". 새벽에 하시더라도 첫 칸이 진짜 오늘이어야 합니다.

## 4. 주소만 넣으면 건물 정보가 채워지는지 (휴대폰)

1. 역할 칩에서 **양도인** → 홈 → **매물 등록하기**.
2. 1단계에서 **[주소 검색 (도로명·지번)]** → `김포한강11로` 로 검색해서 결과 하나를 고릅니다.
3. 그 자리에서 1~3초 기다립니다.

✅ **"🏢 건축물대장에서 가져왔어요"** 카드와 요약 한 줄(예: `1층 · 45.2㎡ · 2009년 준공`) + **[맞아요] [고칠게요]**. [맞아요]를 누르면 층·면적 칸이 채워집니다.
같은 지번에 등록된 업소가 3곳 이하이면 **"이 주소에 ○○으로 등록된 곳이 있어요. 이 업종이 맞나요?"** 카드도 같이 뜹니다.
김포·속초는 자료가 거의 다 있고, 홍대 같은 번화가는 자료가 8%뿐이라 **안 뜨는 것도 정상**입니다(오류 문구가 뜨면 안 됩니다).

## 5. 등록하다 멈추면 이어하기 카드가 뜨는지 (휴대폰)

1. 4번 화면에서 상호·업종(**카페·베이커리 계열**)·보증금·월세·**권리금 3,500**·양도 방식·프랜차이즈 여부를 채웁니다.
2. 아래 **[다음 — 모두가 초안 작성]**.
3. 2단계 화면이 뜨면 **뒤로** → 아래 탭 **홈**.

✅ 양도인 홈에 **"○월 ○일에 하던 등록이에요 · 이어서 마저 하실 수 있어요"** 카드. 눌러 보면 값이 그대로 남아 있습니다. 탐색이나 내 매물 목록에는 나오지 않습니다(아직 게시 전이라 정상).

## 6. 테스트 매물 게시 (휴대폰) — 뒤 번호에서 계속 씁니다

1. 그 이어하기 카드를 눌러 2단계(소개글) → 3단계로 갑니다.
2. **3단계에서 사진은 올리지 마세요.** 7번에서 쓸 재료입니다.
3. 4단계에서 게시합니다. 공개 직전에 **실제 사업자등록번호 10자리**를 넣어야 합니다(없는 번호는 막힙니다. 번호는 비공개로 저장됩니다).

✅ 양도인 홈에 방금 만든 매물이 보입니다. 이 매물을 이 문서에서 **"테스트 매물"** 이라고 부릅니다.
⚠️ 실제 매물(왓더버거 원주일산점 등)은 이 테스트에서 절대 건드리지 않습니다.

## 7. "다음 1개" 카드 — 무엇을 채우면 좋은지 알려주는 카드 (휴대폰)

1. 양도인 홈에서 **내 매물 카드 바로 위**를 봅니다.

✅ 남색 카드 **"사진을 올리면 완성도 ○→○점"** (점수 두 개가 서로 다릅니다). 올라간 점수가 80점 이상일 때만 "'충실한 매물' 배지가 붙어요" 가 따라옵니다. **"사진 슬롯을 늘릴 수 있어요"** 같은 문구는 없어야 합니다.

2. 그 카드를 누릅니다.

✅ 사진 올리는 단계(3단계)로 바로 들어갑니다. 여기서 사진 **1장만** 올리고 4단계까지 가서 수정을 마칩니다.

3. 양도인 홈으로 돌아옵니다.

✅ 카드 문구가 **"사진 2장을 더 올리면 권장 3장이 채워져요 · 완성도 ○점"** 으로 바뀝니다(이번엔 점수 하나).

4. 내 매물 카드를 눌러 매물 상세로 들어가 위쪽을 봅니다.

✅ 같은 카드가 상세 화면 위에도 있습니다.

## 8. 매출이 떨어졌을 때 뜨는 카드 (컴퓨터에서 SQL → 휴대폰)

앱에서는 7일 전까지만 지난 매출을 넣을 수 있어서, 8주치 시험 매출을 SQL로 넣습니다(메모가 `TEST_SEED` 라서 48번에서 한 번에 지웁니다).

**컴퓨터 SQL 편집기**:
```sql
insert into daily_sales (device_id, user_id, sale_date, revenue, memo, source)
select
  '61b3401a-b658-49df-860a-b663a4a273e9',
  '50302ddb-8b08-43d6-8148-6ee7db3aa780',
  (current_date at time zone 'Asia/Seoul')::date - n,
  case when n < 30 then 780000 else 1000000 end,
  'TEST_SEED', 'manual'
from generate_series(0, 55) as n
on conflict (device_id, sale_date) do nothing;
select count(*) as seeded from daily_sales where memo = 'TEST_SEED';
```

**휴대폰**: 사장님 홈을 새로고침하고 **오늘 매출 카드 바로 아래**를 봅니다.

✅ 카드 한 장 — **"최근 한 달 매출이 이전 석 달 평균보다 25% 적어요"**(3번을 건너뛰셨으면 22%) / 아래 줄 "입력하신 매출 기준 · 홍보, 메뉴·운영 점검, 양도 상담을 알아볼 수 있어요" / **[알아보기]** 버튼.
⚠️ **오른쪽 위 ✕는 아직 누르지 마세요.** 14번에서 씁니다.

## 9. 그 카드에서 업체를 찾아보는 시트 (휴대폰)

1. 카드의 **[알아보기]**.

✅ 시트 제목이 카드 첫 줄과 같고, 고를 수 있는 칩이 **양도 상담** 하나뿐입니다(아직 입점 업체가 없어서 다른 칩은 숨김). 칩 목록 맨 아래 회색 글씨 **"정부 지원제도도 확인해 보세요"**.

2. **양도 상담** 칩 → **[매물 등록 미리보기]**.

✅ 제목 **"매물 등록 미리보기"**, 칸을 눌러도 입력이 안 되고, 맨 아래 **[시작하기]**. [시작하기]를 눌러야 제목이 "매물 등록"으로 바뀌면서 진짜 등록이 시작됩니다. 여기서는 **뒤로** 나옵니다.

## 10. 시험용 업체 3곳 넣기 (컴퓨터에서 SQL)

```sql
insert into listings (device_id, listing_type, status, shop_name, address, biz_tagline, biz_category, biz_phone, published_at)
```

## 11. 업체에 전화 걸기 · 관심 표시 (휴대폰)

1. 사장님 홈 새로고침 → 매출 카드 아래 **[알아보기]**.

✅ 이번에는 칩이 **마케팅·홍보 / 양도 상담** 두 개입니다.

2. **마케팅·홍보** 칩.

✅ 업체 2곳. A 줄에는 **[문의하기] [전화하기]** 둘 다, B 줄에는 **[문의하기]** 만. 각 줄 왼쪽에 **♡**.

3. 업체 A의 **♡** 를 누릅니다.

✅ "이 업체 소식을 받아볼게요" 안내와 함께 하트가 채워집니다. 다시 누르면 "관심을 해제했어요".

4. 업체 A의 **[전화하기]**.

✅ 중간에 다른 화면이 끼어들지 않고 바로 전화 앱이 `02-000-0000` 으로 열립니다(**걸지 말고 취소**). 돌아오면 시트가 그대로 있습니다.

## 12. 업체에 문의 보내기 — 자동 첨부와 문의 초안 (휴대폰)

1. 같은 시트에서 업체 **B** 의 **[문의하기]**.

✅ "테스트 홍보업체 B에 문의하기" 시트. 켜져 있는 토글 3개 — 업종 / 지역(서울 마포구) / 상황(최근 한 달 … 25% 적어요). **"최근 3개월 매출 구간 · 월 1,000만~3,000만"** 토글은 **꺼져** 있어야 합니다(돈은 켜야만 나갑니다).
그 아래 본문 칸에 1~3초 뒤 **글이 저절로 채워지고** "초안을 넣어 뒀어요 · 고치거나 지우고 쓰셔도 돼요" 한 줄이 붙습니다. 그 글에 전화번호·주소·금액이 들어 있으면 안 됩니다(비어 있는 것도 정상입니다).

2. **지역** 토글을 끄고, **매출 구간** 토글을 켭니다. 본문 끝에 아무 글자나 하나 더 쓰고 **[문의 보내기]**.

✅ 대화방으로 넘어가고, 첫 메시지에 업종 줄 + 상황 줄 + "최근 3개월 매출 구간: 월 1,000만~3,000만" + 빈 줄 + 본문이 들어 있습니다. **지역 줄은 없어야** 합니다.

## 13. 기업회원 쪽에서 그 문의가 어떻게 보이는지 (휴대폰)

기업회원 역할이 없으면 역할 칩 → 역할 추가 → **기업회원**.

1. 역할 칩에서 **기업회원** → 보라색 홈.

✅ 맨 위 인사말 아래 **"전화 문의 1건"**.

2. 아래 탭 **메시지**.

✅ 위쪽에 "앱 내 문의가 기본 — 번호를 등록하면 전화 문의도 함께 받아요". 12번 대화에 **"매출 상황에서 온 문의"** 라벨과 칩 세 개(답했어요 / 성사됐어요 / 해당 없음).

3. **성사됐어요** 를 눌러 둡니다.

## 14. 정부 지원 연결 카드 세 자리 (휴대폰)

1. 역할 칩 → **사장님** 홈 → 매출 카드 **[알아보기]** → 칩 목록 맨 아래 **"정부 지원제도도 확인해 보세요"**.

✅ "정부 지원제도" 카드에 버튼이 **소상공인24 ↗ 하나만**(정책 도우미는 아직 꺼 둔 상태라 없는 것이 정상) + "정부 사이트로 이동해요 · 모두는 입력 내용을 저장하지 않아요". 눌러 보면 새 창에 `https://www.sbiz24.kr` 이 열리고, 주소 뒤에 `?` 로 시작하는 꼬리표가 붙어 있으면 안 됩니다.

2. 양도인 홈 → 테스트 매물 상세 위쪽.
